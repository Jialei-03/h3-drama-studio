# 响度：目标、真峰值、限幅

> 什么时候读：成片加完配乐要验收时；用户说"太响""太轻""爆音""峰值太高"时；想知道原声该加多少增益时。

可信度：下面的数字都是《Gemini的复仇！》（224 秒，1536×864、24 fps）用 ffmpeg 的 `ebur128` 滤镜实测的**单次**结果。目标值是这部片用户听了认可的值，**不是任何平台的规定**；各平台自己的响度处理规则未验证。

## 1. 目标

| 项 | 目标 | 说明 |
|---|---|---|
| 整合响度 | **约 −15 LUFS** | 作者成片实测 −14.9 LUFS，用户认可 |
| 真峰值 | **−1.5 dBTP 以下** | 实测 −1.6 dBTP；留余量给平台二次转码 |
| 响度范围 LRA | 不管控，13 LU 左右正常 | 文戏轻、打戏重本来就有动态，不要为了好看把它压平 |

## 2. 怎么量

对**最终编码出来的成片**量，不要量中间的 wav（编码会改变真峰值）：

```
ffmpeg -hide_banner -nostats -i 成片.mp4 -af ebur128=peak=true -f null - 2>&1 | tail -12
```

看 `Summary` 里的 `I:`（整合响度）、`LRA:`、`Peak:`（打开 `peak=true` 后是真峰值，单位 dBFS）。`scripts/mix_bgm.py` 混完会自动对编码后的成片跑这条命令，打印 I、LRA、真峰值，真峰值超过 −1.5 dBTP 时提示调低 `limiter.limit`（`--no-measure` 可关）。只量一段时，在 `-i` 前加 `-ss 起点 -t 长度`（例：量打斗段 `-ss 85 -t 65`）。

每个阶段都量一次并记在表里，哪一步把响度或峰值弄坏了一眼就能看出来：

| 阶段 | 整合响度 | LRA | 真峰值 |
|---|---:|---:|---:|
| 拼接 + 冲击帧（更早一版，没有字幕和限幅） | −18.4 LUFS | 13.9 LU | **+1.1 dBFS** |
| 拼接 + 冲击帧 + 字幕（没有配乐） | −18.6 LUFS | 14.1 LU | −0.5 dBFS |
| 加配乐、原声 +4 dB、限幅（最终，歌词不改变声音） | **−14.9 LUFS** | 13.1 LU | **−1.6 dBFS** |

第一行说明：原片没限幅时，真峰值会超过 0 dBFS，放进别的软件里会削波。

## 3. 怎么调

1. **要整体更响，加原片声音的增益，不是把音乐推大。** 原声（对白和音效一起）整体 +4 dB，它们之间的关系不变；音乐跟着原声定，约比原片低 9 LU（[bgm.md](bgm.md) 第 4 节）。为什么：音乐一推大就抢戏，用户嫌过"太响"。
2. **不压低原片声音**，要突出喊招时只放大那一小段（例：+4 dB，前后各 0.15 s 渐变）。
3. **最后一级用限幅器收住峰值**：`alimiter=limit=0.8:attack=5:release=80:level=false`。
   - `limit=0.8` = −1.94 dBFS 的采样峰值；编码成 AAC 后实测真峰值 −1.6 dBTP，比上限高约 0.3 dB（编码和采样点之间的峰值）。
   - 增益提完后原片峰值能到 +3.5 dBFS（爆炸瞬间），限幅器在这些瞬间最多削掉约 5 dB，只持续几十毫秒。**限幅前听一遍爆炸处**，削得太狠会有"泵声"（声音被一下按住）。
   - `level=false`：关掉限幅器的自动电平，否则它会自己把整体抬高。
4. 量最终文件：真峰值超过 −1.5 dBTP，就把 `limit` 再调低一点（例：0.75）重混一次；整合响度太低，就提高原声增益（提完再看爆炸处）。
5. 重混不需要重新渲染画面：配乐一步画面是直接复制的，只重做音频（[bgm.md](bgm.md) 第 6 节）。

作者没有用 `loudnorm` 或整条归一到目标值，而是"增益 + 限幅"；整条归一的效果没试过 [未验证]。

## 4. 验收

1. 整合响度约 −15 LUFS（建议 ±1 LU 内），真峰值 ≤ −1.5 dBTP；
2. 用耳机和手机外放各听一遍：对白听得清，爆炸不刺耳、不"泵"；
3. 从头到尾听音乐：没有忽大忽小（校平没做好会在这里露出来）；
4. 开头静默处、片尾结束处没有咔哒声；
5. 把量到的数字记在成片的版本记录里。

## 5. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 爆炸处刺耳、有"泵声" | 增益提得太多，限幅器削得太狠 | 降低原声增益，或把大爆炸那几帧的声音单独压 2–3 dB [未验证] |
| 对白轻、音乐盖过对白 | 音乐比原声低得不够 | 回到 bgm.md 第 4 节，音乐约比原片低 9 LU |
| 真峰值超过 0 dBFS | 没有限幅，或限幅后又改了增益 | 限幅放在最后一级，再量编码后的文件 |
| 整体偏轻 | 原声没提增益 | 原声整体 +4 dB 起试，再看限幅 |
| 各段忽大忽小 | 片段原声电平不一致 | 作者的拼接没有做逐段响度统一（H3 各段声音电平接近，未单独验证）；若你的片段差别大，在规范化一步给个别段加固定增益 [未验证] |
