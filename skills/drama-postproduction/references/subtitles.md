# 字幕：文字、对时、电影感样式

> 什么时候读：要给成片加对白字幕时；字幕和声音对不上时；想调字幕的样子时；剪片之后要平移字幕时。

规则一句话：**文字以剧本为准，时间用逐词转写在修好的音轨上测，样式走电影感**。H3 画面里不让它自己出字，字幕全部后期叠。

可信度：样式参数是用户逐版看片后定稿的，在整片 40 张字幕卡上使用（**已验证**）；对时流程**已验证**；用其他语音识别工具、其他字体的做法为**未验证**。

## 1. 文字：以剧本为准

- 字幕文字来自**剧本**（定稿的台词），不来自语音识别。为什么：识别会把专有名词听错（例：把"北美 Gemini"听成"北美渣米"），把识别结果直接当字幕，会出现错字。
- 听写只用来**测时间**。听写和剧本对不上的地方，以耳朵为准，改听写不改剧本。
- 一张卡一行；作者的中文字幕最长一行约 16 个字符（含空格和标点），再长就拆成两张卡。
- 行内不用逗号、句号：句内停顿用一个空格，保留 `！` `？` `……` `——`（例：`她……不会真的不来了吧？`、`上次你说了算——这次 换我`）。
- **英文喊招保留英文**（例：大招名 `Skybreaker！`）；不翻译成中文。
- 画面里本来就有的字（片头标题、牌子）不再重复做字幕。

## 2. 对时：在修好的音轨上测

必须先完成拼接和音轨重建（[splice.md](splice.md)）。为什么：v16 拼完音频比画面多 0.75 s，在没修的音轨上测出来的时间，越往后越晚，修好之后全部要重做。

步骤（`scripts/retime_subs.py` 把 1–3 步做完）：
```
python3 scripts/retime_subs.py script.tsv film.mp4 -o cards.tsv --words-cache film.words.json
```
1. 对**成片的音轨**做逐词转写。默认用 mlx-whisper（`pip install mlx-whisper`，Apple 芯片；作者用模型 whisper-large-v3-turbo、`language=zh`、`word_timestamps=True`），没有就用 openai-whisper（`pip install openai-whisper`），两个都没装会给出提示；也可以用别的工具出逐词时间，存成 `[[词, 起, 止], ...]` 的 JSON，用 `--words` 读入。脚本把剧本前 200 个字作为 `initial_prompt`（`--prompt` / `--no-prompt` 可改），对专有名词有帮助。`--words-cache` 把识别结果存下来，下次直接读。
2. 把剧本的每句台词对到转写词上：剧本和转写都切成"单位"（每个汉字一个、每个英文词一个），用最长公共子序列（difflib）做顺序对齐；没对上的字（人名听错、漏字）在同一句里前后对上的字之间插值，只有一侧就按典型字时长外推，**不跨句插值**（句间常有很长的停顿）。每句：起点 = 第一个字的开始，终点 = 最后一个字的结束。
3. 每句给一个匹配率（对上的字数 ÷ 这句的字数）：≥ 80% 标 OK；介于 `--min-match`（默认 50%）和 80% 之间标"低匹配"；低于 `--min-match` 标"没对上"，**不给新时间、保留旧时间**，让你用耳朵定。（验片用的 `scripts/asr.py` 对单段台词按字数依次取词，转写字数不到应有字数的 60% 就标"没对上"；`retime_subs.py` 面向整片，改用顺序对齐，对漏字、多字、听错字更耐受。验片时的一次实测：12 段、30 句台词里 29 句听写对得上，没对上的那句是人名被听错。）
4. 抽查：不止看开头，**开头、中间、结尾各听一处**，字幕出现的时刻对着嘴型；标了"低匹配""没对上"的逐句听。
5. 剪过片或重做音轨之后，字幕时间重新对一遍，见 [rough-cut.md](rough-cut.md) 第 6 节。只是剪片平移的话不用重新识别：`python3 scripts/retime_subs.py cards.tsv --shift 41.7:-0.25 --shift 63.3:-0.5833 -o cards_shifted.tsv`（从 41.7 s 起整体前移 0.25 s，可重复）。

已知局限 [单次实测，2026-11-24，在《Gemini的复仇！》全片 40 句上]：
- Whisper 的逐词时间常把"长静音 / 打斗之后的第一个字"的起点拖回上一句的结尾（一个字被标成 8 秒长）。脚本对每字超过 `--stretch`（默认 1.5 s）的词，按典型字时长从结束往回推起点（`--no-fix-stretch` 关掉）；这是启发式，只在这一部片上试过 [未验证]。
- 和作者用耳朵定稿的时间相比，识别给出的起点在对白密集段通常晚 0.1–0.5 s，个别句到 0.8 s；所以**它是"建议值"，不是最终值**。
- 英文喊招（例：大招名）和英文人名，中文识别常转成谐音字，会被标成"没对上"，这些句子手工定。
- 识别输出繁体字时会和简体剧本对不上；剧本前 200 字做 `initial_prompt` 能缓解，不能根治 [未验证]。

每张卡在测出的时间上再做一点修饰，让观众读得完：

| 参数 | 值 |
|---|---|
| 提前出现 | 0.08 s |
| 延后消失 | 0.30 s |
| 最短显示 | 0.9 s |
| 与下一张之间至少留 | 0.12 s |
| 不得超过 | 片尾 |

## 3. 样式：电影感

用户要的是"电影质感"，所以不用短视频常见的大号纯白字加粗黑描边。参数按 1536×864 写，其他分辨率按画面高度等比缩放：

| 项 | 值 |
|---|---|
| 字体 | 苹方 SC Regular（作者的 macOS）；用 `fonts.zh` 指向一款干净的黑体，例如思源黑体 Regular [替代字体未验证] |
| 字号 | 34 px（约占画面高度的 3.9%） |
| 字间距 | 汉字与汉字之间加 3 px；`——`、`……` 内部和英文单词内部**不加** |
| 颜色 | 暖白 RGB(242, 240, 235)，不用纯白 |
| 阴影 | 高斯模糊 5 px、黑色 75% 不透明、偏移 (2, 3) px |
| 细暗边 | 文字膨胀 1 px，RGB(10, 10, 10)、55% 不透明；白光闪过时字不会消失 |
| 位置 | 底部居中；文字底边离画面底边约 64 px |
| 淡入淡出 | 各 0.12 s（卡片很短时取时长的 1/4） |

另备了一款宋体（Songti SC Regular，36 px，字间距 4 px），最终没有用。

字体文件有授权限制，本仓库不带字体，路径写在 config.yaml 的 `fonts.zh`。

## 4. 渲染

字幕卡文件（`render_subs.py` 的输入，`retime_subs.py` 的输出也是这个格式；示例：`examples/gemini-revenge/data/subs.example.tsv`）：`.tsv` 每行 `起始秒<TAB>结束秒<TAB>文字`，`#` 开头是注释；`.yaml` 写成 `cards: [[起, 止, 文字], ...]`。时间是"语音的起止"，上一节的修饰由 `render_subs.py` 加。

`scripts/render_subs.py cards.tsv IN.mp4 OUT.mp4`：
1. 每张卡单独画成一张透明 PNG（文字 + 阴影 + 细暗边）；
2. 用 ffmpeg 把所有 PNG 放进一条 `overlay` 链：每张 `-loop 1` 输入，`fade` 做淡入淡出（`alpha=1`），`setpts` 移到起始时间，`overlay=x:y:eof_action=pass`；
3. 画面 libx264 crf 16 preset slow yuv420p，音轨 `-c:a copy`，`+faststart`。

参数：字体用 `--font`（或 config.yaml 的 `fonts.zh`，`.ttc` 字体集再配 `fonts.zh_index`，也可以写成 `文件#序号`）；没配字体会直接报错，脚本不内置任何系统字体路径。`--size 34`、`--track 3`、`--bottom 64` 是第 3 节的样式参数（按 1536×864 写，脚本按成片高度自动等比缩放）；`--lead 0.08 --tail 0.30 --gap 0.12 --min-dur 0.9` 是第 2 节的修饰（`--no-pad` 关闭）；`--fade 0.12` 是淡入淡出。想试宋体：`--size 36 --track 4`，字体换成你的宋体。

40 多张卡放进同一条滤镜链没有问题。

渲染前先出预览：`--preview auto`（自动挑最长的一行、含英文的行、含 `……` 的行、含 `——` 的行、第一张）或 `--preview 5.2,36.8`（指定时间点），只合成这几帧的静帧，存到 `--preview-dir`（默认 `./subs_preview`），不渲染整片。还要自己再挑一帧白光闪过的画面看一眼。

## 5. 顺序

- 字幕在**冲击帧之后**：冲击图是全画幅覆盖，先加字幕会被盖住。
- 渲染时只带画面和音轨，**会丢掉嵌入的封面流**，所以封面在字幕之后嵌入（`scripts/embed_cover.sh`，见 `drama-publish`）。
- 字幕在**配乐之前**：配乐一步画面直接复制，字幕已经在里面了。
- 歌词字幕是另一套（[lyrics.md](lyrics.md)），放在最后，位置在对白字幕上方。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 字幕越往后越晚 | 在没修的音轨上测的时间 | 先重建音轨，再重测 |
| 字幕出现了错字 | 用了识别文字 | 一律以剧本为准 |
| 一句话分成两段闪 | 转写把一句拆成两个片段 | 按字数合并，起点终点取整句 |
| 白光时字看不清 | 没有细暗边 | 加暗边（第 3 节） |
| 字幕和歌词叠在一起 | 歌词没抬高 | 歌词块底边 128 px，对白 64 px |
| 剪片后字幕错位 | 没有平移 | 剪点之后的卡片 −N/24 s |
