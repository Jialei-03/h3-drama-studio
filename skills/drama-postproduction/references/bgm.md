# 配乐：只当背景，从结尾反推对齐

> 什么时候读：要给打戏段铺背景音乐时；音乐"对不上拍""忽大忽小""听着像被剪过"时；要调整原片声音和音乐的关系时。

可信度：下面的规则是《Gemini的复仇！》（2026-11-22 至 24）用户反复听、逐版否决和确认后定下的最终结论。具体数字（dB、秒）取自这一首歌、这一部片，换歌要重新量，已按"单次实测"标注。本仓库不含任何音乐，请使用**你有授权的歌**。

## 1. 最终规则

| 规则 | 为什么 |
|---|---|
| 配乐**只在后期统一加**；H3 提示词里把配乐字段写成 N/A | 每段都让模型配乐，几十段拼起来调子一会儿一个 |
| **只铺打戏段**，开场和结尾的对话不放音乐 | 对话要听清；音乐是给打戏添气势 |
| **只当背景**，不抢戏 | 用户嫌第一版（音乐只降了 11 dB）"太响""峰值太高"，之后改按目标响度定增益（第 4 节） |
| **从结尾反推对齐**：让高潮收尾那一句的重拍，落在最后一个大招的冲击帧上 | 用户要的是：歌曲最高潮的收尾和最后一个大招同时炸开；音乐整条连续不剪，只要这一个点对准，前面自然就对上了 |
| 对齐按**实测鼓点起音**，不信逐词识别的时间 | 曾经按识别时间对，差了一拍（约 0.6 s） |
| **音乐本身不剪**，全程连续原曲 | 用户一听就说"好像剪辑了" |
| 音乐电平**全程一致**：只有开头淡入（约 1.5 s）和最后两声被单独推高 | 忽高忽低的压低、推高会被听成剪辑；歌曲自己的轻重变化被打斗声盖住，会觉得"音乐变小了" |
| **不压低原片声音** | 用户明确要求；早期"把原声同频段压低给歌词让路"的做法已否决 |
| 要突出喊招，是**放大原片那一段的声音** | 不动音乐，才不会有起伏感 |
| 原片声音（对白和音效一起）整体可提约 4 dB | 配乐前的原片整体偏轻（−18.6 LUFS），提完才和音乐平衡 |
| 混音后限幅到真峰值约 −1.5 dBTP 以下 | 爆炸瞬间的峰值提完会超过 0 dBFS |
| 不要一上来就切副歌 | 用户："不用立马上副歌"；取歌曲中后段做铺垫 |
| 结尾**不淡出掐断**最后一句，让歌唱到原曲结束；原曲骤停就加混响尾巴 | 用户："不需要把音乐骤然降低" |

## 2. 选曲

- 歌要有授权（你自己购买的、平台曲库里允许用的、免版权的），并确认授权覆盖你要发布的平台。平台的版权识别可能命中，见 `drama-publish` 的 copywriting.md。
- 曲长要能覆盖配乐段，有清楚的鼓点和一个能当"收尾"的高潮句。
- 有两首候选时，各做一版给用户听，让用户选。作者这样做过，不替用户选。
- 逐词识别只能帮你定位大致的句子，卡点用鼓点（第 3 节）。

## 3. 倒推对齐

1. 从冲击帧表里找到**最后一个大招**的峰值帧，换成秒：`T_end`（例：剪前时间线的帧号 3695 ÷ 24 ≈ 153.96 s）。
2. 在歌曲里选"最高潮里收尾的那一句"，找它**重拍的起音时间** `S_end`。找法：对歌曲低频（150 Hz 以下）做频谱通量取起音；用自相关估速度，动态规划跟踪节拍；重拍取每四拍里底鼓能量最大的那一拍；再用波形和耳朵确认。[这套方法在本片用过；其他曲风未验证]
3. 偏移 `OFF = T_end − S_end`，之后**片中时间 = 歌曲时间 + OFF**。
4. 反推出音乐从哪里进：从你想让音乐开始的片中时间减去 `OFF`，就是歌曲里的起点。取歌曲中后段做铺垫，不必进副歌。例（单次实测，剪前时间线）：音乐在片中 81.5 s 进，对应歌曲约 1:48，歌曲 3:08.8 自然结束，落在片中约 162.1 s。
5. 检查：歌曲自然结束的片中时间，要**赶在下一句台词之前**；不够就换收尾句或换曲。
6. 对拍小样：截 `T_end` 前后各 5 秒，正常速度和 1/4 慢放各看一遍，重拍和冲击帧应该同一帧 [做法为建议]。

脚本是 `scripts/mix_bgm.py 配乐.yaml 成片.mp4 输出.mp4 --song 你的歌.flac`：画面直接复制，原声只做增益，音乐在 numpy 里整条算好再叠上去。所有数字（对齐点、淡入淡出、增益、校平范围、推高、混响尾巴、原声增益、喊招增益区间、限幅）都在一份 yaml 里，带注释的示例是 `examples/gemini-revenge/data/bgm.example.yaml`（数字是作者这首歌的实测值，换歌要重量）。脚本只依赖 ffmpeg、numpy、PyYAML，不需要 scipy。

| yaml 字段 | 对应本文哪一节 |
|---|---|
| `tracks[].align: {song_time, film_time}` | 第 3 节：偏移 OFF = film_time − song_time |
| `tracks[].fade_in: [起, 满]`、`fade_out: [起, 止]` | 第 5 节：淡入约 1.5 s（余弦）；不写 `fade_out` 就唱到歌曲自然结束。两首歌接力就写两条 track |
| `music.gain_db` 或 `music.target_lufs` | 第 4 节底盘：给定增益，或让脚本按使用段响度算到目标 LUFS（`measure_range` 指定量哪一段） |
| `music.leveler: {ref, max_db, window, smooth, floor_db, start, ramp}` | 第 4 节校平：2 秒窗口、±8 dB、1 秒平滑，淡入结束之后才渐入 |
| `music.boosts: [{rise: [起, 满], fall: [起, 止], db}]` | 第 4 节：最后两声推高 4 dB；`fall` 省了就保持到片尾 |
| `music.tail: {take, fade_out, wet_db, ir_len, decay_60db, lowpass, predelay_ms, seed}` | 第 5 节混响尾巴；歌自然唱完不骤停就不要写 |
| `film_gain_db`、`shouts: [{start, end, db, ramp}]` | 第 4 节原片声音：整体增益；喊招那一小段再放大，不动音乐 |
| `limiter: {limit, attack, release}` | 第 6 节限幅 |
| `shifts: [{at, delta}]` | 剪过片的平移：所有"片中时间"按写参数时的时间线写，经过它平移后使用，歌曲里的时间不平移（[rough-cut.md](rough-cut.md) 第 6 节） |

`--dry-run` 只打印平移后的时间线；混完脚本会量编码后成片的整合响度、LRA 和真峰值，真峰值超过 −1.5 dBTP 会提示调低 `limiter.limit`。`--work-dir` 把音乐轨、原声轨的 wav 存下来方便单独听。

2026-11-24 用 ffmpeg 合成的测试音（正弦 + 颤音 + 噪声，不是真音乐）在一段 60 秒的真实成片上复测 [已验证流程，未用真音乐]：
- 对齐：歌里 30 s 处的一个短音，落在片中 39.500 s（shifts 平移后的目标是 39.500 s），误差约 0.1 ms；
- 校平：测试音中间有一段比前后轻 12 dB，校平后只比前后低约 4 dB（上限 +8 dB 补回），推高处约 +4 dB，混响尾巴按设定淡出；
- 画面码流与输入 md5 一致（直接复制），带封面的成片混完封面流仍在。
真实歌曲上的听感（"像不像被剪过"）没有在本次脚本整理时重新听；数值参数沿用上面《Gemini的复仇！》定稿时的值。

## 4. 电平

**底盘**：增益 = 目标音乐响度 − 歌曲在使用段的响度。例（单次实测）：这首歌母带很响（整曲 −7.5 LUFS），要降约 14.5 dB；结果是打斗段（片中 85–150 s）音乐约 −21.8 LUFS，同一段原片（已 +4 dB、限幅前）约 −12.7 LUFS，**音乐比原片低约 9 LU**。换歌要重新量，不要抄 14.5。

**校平**（让音乐电平全程一致）：
1. 把已乘增益的音乐按 0.1 s 步长算功率，取 2 秒窗口平均，得到短时响度 L(t)；
2. 参考值 T = 打斗主段内 L 的中位数（例：片中 85–150 s）；
3. 修正量 = clip(T − L, −8, +8) dB，只在 L > T − 30 dB（有声音）的地方起作用，再做 1 秒平滑；
4. 修正量在淡入结束之后才渐入（0.5 s），不改淡入本身；
5. 之后在**最后两声**上再整体推高 4 dB：从最后一个大招冲击帧前约 0.5 s 起渐变上去，一直保持到结尾。为什么：最后两声唱得轻，又落在爆炸后的尘土声里，被盖住。

±8 dB 的上限是为了不把原曲的自然淡出、间奏硬拉起来。

**原片声音**：整体 +4 dB（对白和音效一起，保持它们原有的关系），不做任何压低。喊招要更突出时，把那一小段原片放大约 4 dB，前后各 0.15 s 渐变（例：一段 0.9 秒的喊招）。

作者的配乐段内只有喊招，没有长对白，所以不给音乐做任何起伏。结尾的余音会和战后的两句台词重叠，办法是让余音比台词低至少 5 dB（第 5 节）。如果你的配乐段里有长对白，要另外设计 [未验证]。

## 5. 淡入与结尾

- **淡入约 1.5 s**，余弦曲线（0→1）。6 秒的版本用户嫌慢。
- 结尾让歌唱完。原曲如果最后一声**骤停**（作者这首约 1 秒就断），加**混响尾巴**：
  1. 取音乐最后一声前后约 1.5 s 的片段；
  2. 与合成的大厅混响卷积：8 s 长的指数衰减噪声（衰减常数约 15 s 降 60 dB）、做轻微低通让它更暖、最前 20 ms 置零；
  3. 湿声音量调到原片段 RMS 的 −15.5 dB，叠回音乐；
  4. 余音让它延续 4–6 秒，慢慢淡掉（例：歌曲结束在片中 162.2 s，余音 164–168 s 淡出）；
  5. 尾巴和台词重叠的地方，尾巴要比台词低至少 5 dB。
  [参数为单次实测，用户听后认可]

## 6. 混音与限幅

音乐和原声各自在浮点里算好（48 kHz 立体声，与成片等长），最后一次混合、限幅、编码（`mix_bgm.py` 内部就是下面这条命令，参数取自 yaml 的 `limiter` 和 `aac_bitrate`；`-map 0:v:1` 只在成片带封面流时才加）：

```
ffmpeg -i 画面与原声.mp4 -i 原声_增益后.wav -i 音乐.wav -filter_complex \
 "[1:a][2:a]amix=inputs=2:duration=first:normalize=0,alimiter=limit=0.8:attack=5:release=80:level=false[a]" \
 -map 0:v:0 -map "[a]" -map 0:v:1 -c:v copy -c:a aac -b:a 256k -ar 48000 \
 -disposition:v:1 attached_pic -movflags +faststart 成片_配乐.mp4
```

- `normalize=0`：不让 amix 自己把音量除以 2（该选项需要较新的 ffmpeg，约 4.4 以上 [版本未验证]）。
- `limit=0.8` 约 −1.9 dBFS 的采样峰值，编码成 AAC 后实测真峰值 −1.6 dBTP（单次）。**以编码后的成片为准复测**，超过 −1.5 就把 limit 再调低（见 [loudness.md](loudness.md)）。
- `level=false`：关掉限幅器自动抬电平。
- `-map 0:v:1` 把已嵌入的封面带过去（所以封面要在配乐之前嵌入；成片没有封面流时不要这一项）。
- 画面 `-c:v copy`：这一步不重编码。

## 7. 验收

1. 整合响度、真峰值达标（[loudness.md](loudness.md)）。
2. 最后一个重拍和最后一个大招冲击帧在同一帧；
3. 从头到尾听一遍：音乐有没有"变小""变大""被剪"的感觉——有，就是校平没做到位；
4. 开头淡入自然；结尾余音没压到台词；
5. 喊招、对白听得清；
6. 剪过片之后整套重跑（[rough-cut.md](rough-cut.md) 第 6 节）：`OFF` 和所有时间窗同步平移。

## 8. 试过后放弃的做法（不要这样做）

| 做法 | 为什么放弃 |
|---|---|
| 音乐跟着打斗起伏：大招处推高 6 dB、台词处压低 | 听起来像剪辑；用户要全程一致 |
| 歌词密集段把原声 1–4.5 kHz 压低 5–6 dB、音乐同频段提高 | 用户要求不压低原声，要音乐响度全程一致 |
| 第一版音乐只比歌曲原电平降 11 dB | "太响""峰值太高"，改成按目标响度定增益 |
| 按逐词识别的时间对齐最后一句 | 差了一拍（约 0.6 s） |
| 6 秒淡入 | 太慢 |
| 一上来切副歌 | 用户不要 |
| 最后一句淡出掐断 | 用户要唱完；骤停的原曲用混响尾巴 |
