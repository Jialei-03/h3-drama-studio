# 短剧出片：文戏方案与武戏方案

先判断这一段是文戏还是武戏。两者的 LoRA、段长、时间码、节奏、衔接都不同，**不能混用**：战后的对话挂着武戏配置出片，画质就比打戏之前糊。

| | 文戏 | 武戏 |
|---|---|---|
| 采样配置 | 专属二采：一采 1024×576、10 步 → 潜空间放大 ×1.5 → 1536×864 二采 | 同左 |
| LoRA | 一个都不挂 | 武戏链：融合 DMAD 0.8 + MysticXXX 0.35 + 速度滑块 3 + H3_Combat_V2 0.65 + Motion_Repair_V2 0.35 |
| 参考图 | 人物定妆图 + 场景图 | 人物定妆图 + 场景图（有召唤物再加召唤物图）；**不用关键帧** |
| 段长 | 最长 12 秒，在自然的镜头边界结束 | 5–10 秒，超过就拆段 |
| 镜头数 | 2–5 个，每一刀要说得出理由 | 不设上限，按内容定 |
| 时间码 | 不写，事件挂在台词或动作上 | 每个镜头、每一拍都写 |
| 节奏 | 平静；提示词里不留任何“动作快”的描述 | 第一帧就是全速；越到结尾越快，收在冲击或闪白上 |
| 台词 | 多、句子长；每秒 4–5 个汉字；先走到位再说话 | 不说话；只有招牌大招在动作中途用英文喊一声 |
| 生成方式 | 可以排队批量出 | **一次只渲一段**，看完再写下一段 |
| 段间衔接 | 停在完整节点就硬切，站位对上即可 | 接上一段末尾 22 帧加音频，拼接时剪掉并做颜色匹配 |
| 耗时（RTX 5060 Ti 16 GB，1536×864，24 fps） | 每秒成片约 1.5–2 分钟 | 每秒成片约 2.4–2.7 分钟 |

配置的细节（模型、LoRA 下载、步数、sigma）不在这个 skill 里，见 [../h3-video/references/recipes.md](../h3-video/references/recipes.md)。

## 怎么判断是哪一类

- 有大段台词、走位、表情、情绪 → 文戏。有招式、能量、命中、召唤物 → 武戏。
- 同一段里既有长台词又有打斗 → **拆成两段**。打斗中一有台词，H3 就让人站住对口型，动作就停了。
- 只有招牌大招可以在武戏里出声（英文，动作中途喊一声）。
- 打戏前后的对话、战后的收尾，都按文戏的配置出。紧接在打戏后面、画面必须接上的那一段文戏是例外：要接上一段末尾 22 帧，也可以写时间码，见 [dialogue.md](references/dialogue.md)。

## 每一段的流程

1. 判断类型，查全片状态表（方位、伤、持械、场景受损阶段，见 drama-preproduction）。
2. 按 [prompt-structure.md](references/prompt-structure.md) 的骨架写，再按文戏或武戏的方案补镜头。
3. 跑 `scripts/check_script.py` 做机械检查。
4. 渲染。文戏可以排队批量出；武戏一次一段。
5. 验片（[qc.md](references/qc.md)）：切点、听写台词、截帧、接缝；判定留用、换种子或改提示词；记 take 表。
6. 武戏：把这一段**实际的**结尾状态抄进下一段的开头，再写下一段。

## 必须遵守的规则

**通用**
- **写了的东西都会被画出来**，包括设定说明。站位里写“地面中央一个焦坑”，每一段都画出一个大坑。不想画的，一个字也不写。
- **没挂参考图的人不要写进站位**：模型会在地面边上画几个陌生人。
- **容易漂的细节写死在角色描述里**：异色瞳、领口、持械的手（左右、正手反手）、武器是实心钢剑不是光束。一句“瞳孔里的星亮了”就把一蓝一金盖成了两只蓝眼。
- **连续性细节每段都要重写**：伤、嘴角的血、持剑的手、高跟鞋脚步声（写进 `overall_soundscape`）。每段都是独立生成的，模型不记得上一段。
- **想要一镜到底，提示词里所有 `Shot 2` / `hard cut` 字样都要删干净**：summary、retention_analysis、结构句、镜头正文，只改一处模型仍会切。
- **不用关键帧；每个镜头先写起始机位，再写运镜**（[camera.md](references/camera.md)）。
- 方位固定、人物间距写具体数字，否则两人距离忽远忽近。
- 排除项写成正面描述；这个流程没有负面提示词，“不要 X”可能反而把 X 带进画面。

**文戏**（[dialogue.md](references/dialogue.md)）
- 每一刀要有理由（新信息、换人说话、看反应、距离或朝向变化、关键事件）；不按固定秒数切（1.5 秒一切被嫌“切屏太快”）。
- **不写时间码**：写“00:07 睁眼”，模型晚约 2 秒才睁眼。
- 点名说话人，倾听者闭嘴，一句台词不跨镜头；声线定稿后逐字沿用；边走边说会让人停下来，先走到位再说。
- 提示词里不留“动作快”的描述，用平静节奏的句子；不要每个镜头都加“淡淡尘雾”，画面会发灰。
- 同一个梗不跨段复读，一件事只在一段里演；下一段要演的事，上一段只给引子。
- 不挂任何 LoRA。

**武戏**（[fight.md](references/fight.md)）
- **一次只渲一段**：一股脑排队生成，段与段对不上，像拼凑。
- 每个镜头每一拍都写时间码；第一帧就是全速；结尾收在冲击、闪白或被吞没上，不停在静止画面（停住的结尾会让最后一秒的运动量从约 15 掉到约 2）。
- **速度只用正面描述**：不写 `no slow motion`、`never pauses`，这类写法可能把慢和停带进画面。
- 每段只放能演完的动作量，一两个动作；人物间距写数字，本段谁都不挪步。
- **人物不能干等**：占上风的人接着出手，不要在接续开头写“两人对峙一拍”。
- 少拳脚，多能量对轰；近身写“兵器在一臂之距相撞，身体不碰”；每次命中有四样结果：闪光碎屑、被打飞、表情、留下的伤。
- 特效写成团、片、浪，并写和柱子、看台的比例；两人都是人的身高，只有召唤物巨大（[summons.md](references/summons.md)）。
- 破坏只做小范围（石板碎裂、浅坑、碎石）；受损的场景靠分阶段的场景参考图，不靠文字。
- 打斗中不说话；招牌大招一人一个、英文、动作中途一口气喊出。
- **通用规则会被当成必须出现的镜头**：单人段、巨兽段不套用两人对打的规则；每段写明“视频只由下面这几个镜头组成”。
- 接续：上一段末尾 22 帧加音频锚在新段第 0 帧，拼接时剪掉并做颜色匹配；接缝两边画面完全不同时跳过颜色匹配（[continuation.md](references/continuation.md)）。
- 只给真正的大招预留冲击帧位置。

## 可信度

文件里的结论带标注：**已验证**＝多次出片确认；**单次实测**＝只在一两段上看到；**未验证**＝推断或没对照过。所有数字都是 RTX 5060 Ti 16 GB、1536×864、24 fps 下的实测。文戏最长 12 秒是作者定的上限，原因没有记录，更长的段没试过。
