# 致谢：配方和方法的来源

什么时候读：想知道某个做法最初是谁想出来的、要去看原教程，或者要在自己的作品里署名时。

本仓库的配方和方法来自多位创作者公开分享的视频、教程和工作流。这里只写**学到了什么**和出处，不收录他们的提示词原文，不分发他们的工作流、整合包或模型文件。要用，请去原作者那里取，并遵守他们的使用条款。所有链接目前都是"待补"，由仓库维护者补上。

## 配方每一项出自哪里，本仓库改了什么

分清"照抄的"和"自己改过、测过的"，方便你判断哪些可以放心沿用，哪些要自己再验证。

| 配方项 | 出处 | 本仓库的情况 |
|---|---|---|
| 二采的整体结构（一采 → 潜空间放大 → 在中途切开二采） | 吃猪侠233 的专属二采，他说以金鱼的节点框架为基础 | 沿用结构 |
| 一采 10 步 sigma 曲线 | RunningHub 上流传的 10 步工作流 | 沿用 |
| 二采 beta 14 步、第 8 步切开、SigmaShift 12/3 | 吃猪侠233 | 沿用 |
| 一采分辨率 | 吃猪侠233 原版为 1056×608 | 改为 1024×576：1056×608 慢约两成，看不出差别（单次实测） |
| 放大倍数 | 吃猪侠233 原版约 1.8 倍 | 改为 1.5 倍：1.8 倍在 16 GB 上一段约 47 分钟（单次实测） |
| 不挂 LoRA 的文戏 | 吃猪侠233 的无 LoRA 画质增强流 | 沿用 |
| 武戏 LoRA 链 | 金鱼的 DMAD、MysticXXX、速度滑块、武戏三件套 | 取其中五个，强度照其工作流；文戏不挂是本仓库的结论 |
| 武戏接续（末尾 22 帧加音频） | 惊尘 | 沿用；颜色匹配用自己写的 `chain_join.py` |
| 武戏不用关键帧、起始机位靠文字 | 本仓库自己的结论（作者看片认可） | |
| 文戏、武戏配置分开 | 本仓库自己的结论 | |
| 队列、STOP 文件、`shots.json` | 本仓库自己写的 | |
