# 出稿前审稿：三遍人工审 + 一遍机械检查

什么时候读：整集（或一批段）的中英文提示词写完、还没排队出片之前。出片一段要等十几分钟到半小时，审稿几分钟，所以先审。

## 1. 怎么做

1. 备好材料：**中文全剧本、逐句中文翻译、英文提示词、全片状态表、角色卡、段落清单**。
2. 找三个**互相独立**的审稿者（例：三个子 agent），各自用不同的身份读同一批材料，**只列问题，不改稿**。
3. 每条意见按这个格式写：`段号 | 问题 | 为什么是问题 | 建议改法 | 严重程度（高/中/低）`。
4. 主 agent 汇总、去重、改稿；改完跑第 4 节的机械检查。
5. 全部"高"和"中"清零后，把**中文全剧本和逐句翻译给用户过目**，用户确认才排队出片。
6. 改动很大时（例如重写了状态表或节拍），把三遍审稿重做一遍。

为什么分三个身份：同一个人通读一遍，会被故事牵着走，看不出构图和接缝上的问题。作者的 v12 整集重写，三方审稿各自查出了不同类别的问题（见第 5 节的通病表）。

## 2. 三种身份各查什么

### 作家：故事和台词

| 查什么 | 例子 |
|---|---|
| 动机通不通：每个人这时为什么做这件事 | 对手为什么此刻挑衅，主角为什么忍到现在 |
| 台词有没有复读：同一个梗、同一条设定是否出现不止一次 | "三个月""北美豆包"出现七八次（全部删掉）。一个梗最多铺垫一次、回响一次，回响要带新信息 |
| 每句台词是否推进剧情，而不是回头念旧账 | 设定只在开场交代一次 |
| 情绪是否连贯：上一段结束的情绪，这一段是否接得上 | 认输之前，对手的态度要有变化过程 |
| 每段有没有落点：看完这一段，观众知道了什么新东西 | 没有新信息的段，删掉或并掉 |
| 打戏是否升级、占上风的人是否干等 | 打戏每段都要改变局势 |
| 每个角色说话是否像她自己；声线描述是否逐字沿用 | 配角拆台、反派傲慢、主角克制，三种句式 |
| 台词量：每段是否超过预算（每秒 4–5 个汉字） | 超预算的台词会被说不完 |
| 钩子：开场第一个镜头是人物近景再拉开吗？结尾有钩子吗？ | — |

### 漫画家：画面和空间

| 查什么 | 例子 |
|---|---|
| 每个镜头的构图读不读得懂：谁在画面哪里、占多大、朝哪 | "画面左、画面右、中央、前景、远处"，不用代词 |
| 方位、座位、持械、地标是否和状态表一致 | 座位左右反了、持剑手写成左手 |
| 左右关系和朝向在跨镜头时是否保持 | 镜头始终在两人连线的同一侧 |
| 近侧机位能不能拍到你写的东西 | 伤口、持械手在背面时，镜头拍不到 |
| 没交代清楚、模型会自己乱编的地方 | 没写场地，背景长成沙漠；没写座位，多出陌生人 |
| 写了但不想画进去的东西 | 设定说明里的"焦坑"会被画出来 |
| 尺度是否写成可比的东西，每段有没有尺寸参照 | "比巨柱还高、横跨半个擂台" |
| 每个出场的人、召唤物、场景是否都有参考图；没有参考图的人是否被写进了站位 | — |

### 动画导演：动作、衔接、运镜

| 查什么 | 例子 |
|---|---|
| 交界处：动作没完成的接续，完整节点的硬切 | 龙冲向镜头的下一段，先演完龙被拍飞，再切到人脸 |
| 每个镜头的起始状态和结束状态是否清楚 | 结尾是好帧，不是闪白、残影、糊帧 |
| 每镜是否写了运镜（类型 + 幅度 + 速度 + 动机），一段里是否重复 | 静止也要写"Static Shot" |
| 文戏有没有时间码，武戏有没有时间码；节奏句对不对 | 文戏不写"动作快"；武戏第一帧全速、收在冲击上 |
| 有没有写否定式的速度词（"no slow motion"） | 写成正面描述：每一帧都按真实速度播放 |
| 特效尺度够不够、双方是不是同一量级 | 一方的特效是另一方的几分之一，看起来像单方面碾压 |
| 物理逻辑：怎么落地、往哪个方向劈、裂痕方向、残影去哪里 | 空中劈下的人写"稳稳落地、单膝收势"；分身消散后要合体，写成流光汇回本体 |
| 一件事是否只在一段里演；事件是否交代完 | 召唤物消失、人物落座、对手离场 |
| 冲击帧和大招的位置是否预留 | 只给真正的大招 |
| 接续那一帧：下一段第一镜是不是从这个画面出发 | 写成"镜头从这一帧出发、绕过去" |

## 3. 通过标准

- 三份意见里没有未处理的"高"和"中"
- 第 4 节的机械检查无报错
- 用户看过中文全剧本和逐句翻译并确认

## 4. 机械检查（`scripts/check_script.py`）

用法：`python3 scripts/check_script.py shots.json --rules rules.yaml --data segments.yaml`。脚本里只有**通用检查**；作者片子专属的规则（右手握剑、座位左右、坑出现的时机……）放在一份规则 yaml 里，写法见 `examples/gemini-revenge/data/rules.example.yaml`，你的故事把自己的禁用写法、座位表、招牌大招加进去。`--data` 给 `build_shots.py` 的数据文件，就按角色表自动检查“站位里的人物是否都挂了参考图”。错误（E）让退出码为 1，警告（W）只提示，加 `--strict` 才算失败。

**脚本自带的通用检查**（不用写规则就会跑）：

| 检查 | 规则 | 为什么 |
|---|---|---|
| 段长 | 不超过 12 秒；武戏不超过 10 秒；带接续（ctx）的段新内容不超过 9.9 秒、含 22 帧共不超过 260 帧（上限都可在规则文件里改） | 12 秒是作者定的上限；武戏超过 10 秒要拆段；260 帧是 16 GB 显存的安全线（未验证更长的） |
| 占位符 | 提示词里不能残留 `{…}`；`<Subject N>` 的 N 不能超过挂的参考图张数 | 模板没替换完就出片，白跑一段 |
| 站位人物挂图 | 站位里出现的人物、召唤物，必须挂了对应的参考图（`--data` 自动按角色表查，也可在规则里手写 `ref_required`） | 没挂图，人物或召唤物外形每段不一样，甚至画出陌生人 |
| 武戏时间码与结构句 | 武戏每个镜头都要有时间码（`0.0–2.5 s.`）；最后一个镜头的终点和段长对不上给警告；每段武戏要有规则文件 `fight_required_phrases` 里的句子（例：“视频只由下面这几个镜头组成”） | 没写时间码，模型自己分配时长；通用规则会被当成必须出现的镜头 |
| 打戏台词 | 武戏段里的台词只能是规则文件 `signature_moves` 里的招牌大招 | 配了台词，人就站住对口型 |
| 文戏 | 文戏写了时间码给警告；台词字数除以秒数超过 5（`max_chars_per_second`）给警告 | 文戏事件挂在台词和动作上；超预算的台词说不完 |
| 禁用词表 | 规则文件 `banned_words` 里的词出现就报错（例：`no slow motion`） | 速度、停顿类的否定词会把"慢"带进画面 |
| 衔接锚点 | 引用的上一段必须存在；声明了首帧/接续的段，第一镜要写"从锚定画面/上一段中途开始"、站位要写"接续上一画面"；没有锚点的段不能写"接续" | 写了接续没有锚点，模型会瞎编开头 |

**规则文件里的项目专属规则**（作者片子的例子在 `rules.example.yaml`，换成你自己的）：

| 规则类型 | 例：作者的片子 | 为什么 |
|---|---|---|
| `banned`（正则命中，且前后一句里没有 `unless` 限定词就报错） | 出现"左手""反手握"时必须带"绝不"；出现"着火 / 燃烧"时必须有来由；出现"看向镜头"时必须带"没有人 / 绝不"；前排座位左右反了 | 持械手画反过两次；没有来由的着火被点名；作者不要正脸摆拍；座位反了出现过 |
| `not_before`（某写法不能早于某一段） | 炮击后才有的坑，不能出现在它之前的段里 | 场地状态要前后一致 |
| `required`（必须写的句子，可限定 `kinds`） | `non_diegetic_music` 要写 N/A | 配乐在后期统一加，每段让模型配会一会儿一个调 |

## 5. 常见通病（作者 v12–v14 审稿查出）

| 现象 | 原因和办法 |
|---|---|
| 台词说不完、人物站着不动对口型 | 超预算，或边走边说。按每秒 4–5 个汉字算，先走后说 |
| 近侧机位拍不到伤口和持械手 | 伤口写在朝向镜头的一侧；持械手写明在远侧、剑柄从身后露出，或换机位 |
| 下一段从一张废帧开始 | 接续的那一帧必须是清晰的好帧，不是闪白、残影；第一镜写成"镜头从这一帧出发" |
| 从擂台一侧拍看台，却写了她们身后的擂台 | 擂台在镜头背后：人物越过镜头看擂台，光和碎石从镜头后方扫来；不写身后的擂台 |
| "特效比巨柱还宽"等尺度没法比较 | 写"比巨柱还高、横跨半个擂台"；每段写尺寸参照 |
| 没挂参考图的人被画成陌生人 | 站位里不写没挂参考图的人，写明"地面上除了两人，没有任何人" |
| "断成两截"画出三四把剑 | 写成"那一把剑断成的两截，带剑柄的一半和带剑尖的一半；画面里没有别的剑" |
| 场景损坏靠文字保不住 | 每个受损阶段一张场景图；只让地面受损，柱子永远不坏 |
| 冲向镜头的巨物很慢 | 镜头可以往后甩，但对象要快得多；结尾不要停在静止画面，收在冲击或闪白 |
| 急推到撞击点再闪白、甩回大全景，出来一片雾蒙蒙 | 打斗第一帧就全速；中间切一个人物近景（闪避时凶狠的一笑）比纯特效好看 |
| 两人近身交手画成胸口相撞、像拥抱 | 写兵器或招式在一臂之距相撞，并写明身体始终不碰 |
| 异色瞳被盖成两只蓝眼，上衣长出高领 | 这类细节写进角色描述并写死 |
| 一件事在两段里各演一遍，上一段停在半空 | 下一段要演的事，上一段只给引子，停在引子上，段长相应缩短 |
| 召唤物消失、人物落座没人交代 | 每件事都要有一个镜头或一句话；召唤要有触发动作，上一段埋下 |
| 通用规则里的画面被当成必须出现的镜头 | 只有一人或只有巨兽的段不套两人对打规则；每段写明"视频只由下面这几个镜头组成" |
| 扬尘让背景变成沙漠峡谷 | 第二镜补一句环境锚点：石板、柱子、看台 |
| 同一个角色眼睛颜色被改 | 在角色描述里写死颜色，并写"眼睛不发光" |
