# 故事节拍、人设与台词风格

什么时候读：写第一个提示词之前，把一个点子变成"节拍表 + 角色卡 + 台词规矩"；或者拿到别人的故事，要判断能不能拆成 AI 短剧。

## 1. 先定篇幅和范围

- **一集只讲一件事。** 作者的片子是"被看不起 → 闭关归来 → 当场打脸 → 登上榜首 → 留一个下一位对手的钩子"，一句话讲得清。
- **每多一个有脸的角色、场景、召唤物，就多一张定稿参考图、多一份状态表、多一个串脸的机会。** 作者最终的规模：5 个角色、2 个召唤物、4 个主要场景（星洞、山崖、擂台、前排包厢）。范围越小越稳（推断，未验证）。
- **篇幅的演变（作者这部片）**：最初计划 77 秒、8 段；整集重写后 19 段、199 秒；成片 3 分 44 秒、24 段留用片段。打戏从最初的 3 段约 30 秒，加到 8 段约 80 秒，最终 11 段 96 秒。篇幅是随"打戏要够长"一路长出来的，开工前不必一次定死，但每一版都要先有节拍表。
- **不要先写提示词。** 作者的教训是"故事 > 提示词 > 工作流 > 模型"：看片时被挑出来的是"剧情没看头""台词太少""空镜太多"，没有一条是采样步数。

## 2. 节拍表（先写这个，再拆段）

下面是通用骨架，右列是作者片子的对应，标"例："。

| 节拍 | 作用 | 例：《Gemini的复仇！》 |
|---|---|---|
| 钩子 | 前 10 秒留住人；抛出"前情"一句，只说一次 | 闭关的她睁眼，心声回想被嘲笑的那句外号 |
| 出发 | 主角为什么现在行动 | 出关，唯一知情的朋友在崖边送行 |
| 对手立起来 | 反派/对手自己先有一场戏，让人看到她强在哪、多傲 | 三连冠的卫冕者独自在台上嘲讽鸦雀无声的看台 |
| 配角制造期待 | 观众替主角着急或期待 | 看台前排两个配角闲聊，一声尖啸，两道流光飞来 |
| 登场 | 主角落地，不破坏场地 | 流光掠过擂台，轻巧落地，地面完好 |
| 对峙 | 一来一回的嘲讽和回击，立下"这次换我" | "躲了这么久，就练出一双跑得快的腿？""不。上次你说了算——这次，换我。" |
| 开赛 | 交代距离、站位、规则，让打戏有起点 | 两人各退几步，广播宣布开赛 |
| 打戏（多段） | 全片亮点，见第 3 节 | 11 段 |
| 余波 | 爆炸之后的寂静，配角担心，烟散 | 云海被炸平，豆包问"两个人都还好吗" |
| 和解/认输 | 对手承认，把戏的情绪落下来 | 对手被拉起来，说"下一次，我会赢回来" |
| 收束 | 榜单、配角的喜剧收尾 | 石碑上光牌升到最顶，配角问押注能不能退 |
| 钩子 | 留下下一位对手 | 朋友站起来说"下一个，轮到我了" |

- **开场钩子的写法（通用）：第一个镜头先给人物近景，再拉开交代环境。** 为什么：作者第一版开场是"大场景里一个小人"，观众看不清她是谁，留不住人。
- **一个梗可以铺垫一次、回响一次，回响必须带新信息。** 例：看台配角在开战前说"我押她十块钱，赚得我都困了"，登顶后配角问"押对手的十块钱能退吗"。
- **现实映射可以做，数字取整，不当精确数据。** 例：把现实里的榜单名次写成石碑上的光牌分数。
- **借梗不借脸。** 拟人化或恶搞现实对象时，原创反派只借"皮衣、显卡"这类梗，不使用任何真人的长相和姓名。公司、产品拟人化是否合规，请自己对照平台规则。

## 3. 打戏的节拍（打戏是全片亮点）

- **结构：势均力敌 → 各出绝招互拆 → 看似败局 → 反杀 → 终结大招 → 寂静。** 为什么：作者第一版打戏被嫌"只是挥舞一下手臂或者剑"，没有来回。
- **每一段结束时，局势和开始时不一样**：谁占上风、谁添了伤、场地多了什么。段内没有变化，就不要这一段。
- **占上风的一方要接着出手**，不要举着武器干等。换招、升空都要有被打断或借势的理由。为什么：一段里占上风的角色举着刀干等，作者看片当场指出，这个 take 被弃用。
- **打戏段数要多于文戏段数**（至少是打戏时长不少于文戏）。为什么："这么强的 AI 不能打几下就结束"。例：成片 24 段里，战前文戏 6 段，打戏 11 段，战后 7 段。
- **升级阶梯，例：** 对轰 → 召唤物登场 → 对方召唤物拦截 → 双方召唤物同归于尽 → 对手赌上一切的一斩 → 烟尘里反杀（分身围攻）→ 终结大招 → 大爆炸与寂静。
- **召唤物不必是人形**，用动物或自然物（例：银龙、星辰灵猫），轮廓清楚，也最容易写出尺度对比。召唤要有触发动作（扬手、挥剑），由上一段埋下。
- **主角不打召唤物，伤害要落在对手本人身上。** 召唤物对召唤物，或者穿过召唤物去打召唤者。
- 具体写法（接续、运镜、速度）见 `../../drama-scenes/references/fight.md`。

## 4. 角色卡（每个角色一张，写完不再改）

| 字段 | 写什么 | 为什么 |
|---|---|---|
| 名字、一句话 | 身份加一个性格词 | 台词和表演都从这里长出来 |
| 弧线 | 开头的状态 → 结尾的状态 | 每段表演要能说出"她这时处在弧线的哪里" |
| 标志色 | 一种颜色 + 一种光效（例：蓝紫星光、银紫龙光） | 特效一眼分谁的 |
| 外观锁定项 | 发型发色、眼色、服装关键件、配饰，写成能直接放进提示词的一句话 | 模型会漂：一句"瞳孔里的星亮了一下"把异色瞳盖成两只蓝眼 |
| 易漂移细节 | 把最容易被画错的点单独写死（例：右眼蓝、左眼金，瞳孔里没有星星；上衣没有领子） | 特写里服装会自己长出高领 |
| 持械、招式 | 持械手、握法、一个招牌技和它的英文名 | 持械手全片不变；见 `state-table.md` |
| 声线 | 一句话：年龄感 + 音色 + 语速 + 语气（例：成熟的年轻女声，圆润优雅，傲慢，尾音略拖） | 定稿后每段逐字沿用，否则同一个人每段声音不同 |
| 体型 | 和别人的身高关系、与场地的尺度关系 | 人物不能忽大忽小；见 `state-table.md` |

- 角色之间的差异靠**颜色、轮廓、语气**拉开，不要靠"她更美"。
- 配角各给一个固定功能（例：一个负责替观众发问，一个负责拆台），每次出场台词都不一样。

## 5. 台词风格

| 规则 | 为什么 |
|---|---|
| **台词多、句子长，不留空镜。** 文戏每段至少两句；一句台词可以有 15–30 个汉字 | 作者第一版"台词太少、空镜太多"，被明确批评 |
| **同一个梗不跨段复读。** 设定交代一次就够，每句台词推进剧情，不回头念旧账 | 第一版里"三个月""北美豆包"各出现七八次，作者看片说"完全没必要"，全部删掉 |
| **打斗中不说话。** 只有喘息、闷哼、吃痛声；每人最多一个招牌大招，在动作中途用英文喊一声（例："Skybreaker!"、"Supernova!"） | 只要配了台词，H3 就让人站住对口型，动作就停了；中文招式名被嫌不好听 |
| **点名说话人，倾听者闭嘴，一句台词不跨镜头**；内心独白要写明嘴闭着 | 否则两个人同时动嘴，或一句话被切成两半 |
| **说话人换了就切镜，一个镜头只给一个人说话** | 一镜多人说话，口型和声线都会串 |
| **边走边说会让人停下来对口型**：先走到位，停下再说 | 走位和台词抢时间，走位那一半会被吞掉 |
| **声线定稿后逐字沿用** | 每段重写一遍声线描述，声音就会变 |
| **广播、画外音写成"从场地本身传来的声音"**，画面里不出现播报员 | 写成人说话，模型就画一个播报员出来 |
| **台词量按时间预算算**：每秒 4–5 个汉字，再留出动作和音效的时间 | 见 `script.md`；超预算的台词会被压快或说不完 |

例（文戏对白，取自作者片子）：
- 卫冕者："还有谁？三年了，这论剑台上，就没有一个人能让我拔出第二剑。"
- 主角："不。上次你说了算——这次，换我。"

## 6. 故事阶段的验收

- [ ] 一句话讲得清这一集
- [ ] 节拍表里，每个节拍都有"新信息"，没有只为了交代设定的段
- [ ] 打戏至少 5 级升级，每级都改变局势
- [ ] 全部台词列成一张表后，找不到两句意思相同的
- [ ] 每个角色有角色卡、一句声线、一个会漂移细节的清单
- [ ] 每个召唤物有触发动作，并且在上一段埋下
- [ ] 最后有钩子
- [ ] **给用户（做片的人）看过节拍表和角色卡并确认**，再进下一步（`ref-images.md`）
