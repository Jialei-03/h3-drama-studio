# 全片状态表：让每一段都在同一个世界里

什么时候读：开始写第一段提示词之前建表；写每一段站位时来查；出片后发现左右反了、伤口消失了、柱子又立起来了、人忽大忽小，回来查是哪一行没写或没照抄。

## 1. 为什么需要它

每一段视频都是单独生成的，模型不记得上一段。**状态表就是这部片的场记**：把方位、座位、光线、尺度、场地状态、人物衣着和伤、持械方式，各写成一句固定的话；每一段的"人物站位"只能由表里的句子拼成，不手写。

- **固定说法一字不改，直到状态真的变了。** 为什么：同一件事每段换个写法，模型就当成不同的东西画。
- 把这张表放在 `project.dir` 下的一个文件里维护。每段的站位由脚本（见 `scripts/build_shots.py`：状态表的每一行写成数据文件里的一条 `phrases`，站位里用 `{@名字}` 引用）或你自己按"适用段"那一列从表里拼出来，不要在提示词里重写。

## 2. 要写哪些行

| 类别 | 写什么 | 例：作者的片子 |
|---|---|---|
| 方位 | 对打双方在场地的哪一半、面朝哪边；镜头留在两人连线的哪一侧 | 挑战者站左半边、画面左、面朝右；擂主站右半边、面朝左；镜头始终在两人连线的近侧 |
| 座位 | 看台和前排每个座位是谁，没到的人座位空着 | 前排：DeepSeek 左、豆包中、Claude 右；Claude 到场前右边座位空着 |
| 外景地标 | 远景里重要地标在画面里的固定位置 | 擂台始终在画面右上方、太阳旁边 |
| 光线 | 光从哪来、什么色 | 金色夕阳，低垂的太阳在画面右侧，暖色轮廓光和薄雾 |
| 尺度 | 人高、柱高是几个人高、场地大小，写成可比较的东西 | 两人都是普通人的身高，一人高半个头；每根巨柱约五个人高；擂台像体育场，约两百步宽 |
| 场地状态 | 场地在每个阶段的样子；对应一张受损阶段场景图 | 完好 → 对轰后（焦痕和犁沟）→ 局部损坏 → 战后（蓝火熄灭、旗帜撕走） |
| 人物状态 | 每个人每个阶段的衣着、伤、头发 | 完好 → 沾灰 → 袖子撕开、颧骨一道口子 → 礼服烧焦、翼撕裂、剑断成两截 |
| 召唤物 | 外形、尺度、站位 | 每次出场外形描述一字不差；出手后回到召唤者身边护着她 |
| 持械 | 持械手、握法、拖剑时剑在哪 | 全片右手正手握剑；拖剑时剑在身后，剑尖在脚跟后面 |
| 声线 | 每个角色一句声线描述 | 见 `story.md` 角色卡 |

## 3. 规则

| 规则 | 为什么（作者踩过的坑） |
|---|---|
| **伤和破坏只累积、不消失。** 衣服撕破、流血、焦痕、熄灭的火，后面每段都要写 | 状态不写，下一段就是干净的衣服 |
| **每次状态变化都要在画面里有来由。** 受伤只写"被打中之后"的伤；不要写没有来由的伤或火 | 披帛"莫名其妙着火"被作者点名 |
| **落地、登场不破坏场地**，除非剧情需要 | 一次登场落地砸出一个洞，被作者点名 |
| **破坏只做小范围**：石板碎裂、浅沟、浅坑、碎石、焦痕。深渊、大裂谷、整块擂台崩塌不要 | 大范围破坏前后很难一致；作者的深渊版结尾场景图最终重画成局部损坏 |
| **柱子这类地标永远不坏**，只让地面受损 | 文字写"断柱"保不住，三段里柱子又立回来 |
| **场景状态靠参考图，不靠文字**：每个受损阶段一张场景图 | 地面的坑写文字能保住，断柱保不住；见 `ref-images.md` |
| **尺度写成可比的东西**："比巨柱还高、横跨半个擂台"。不写"比巨柱还宽"（柱子本身很细）。每段站位都带尺寸参照；有巨物的段要写明谁是巨物 | 特效太小被作者批评；"比柱子宽"没有意义 |
| **人物体型固定**：都是普通人的身高，只有召唤物巨大；不要写 colossal、towering 这类会套到人身上的词 | 人忽大忽小 |
| **间距写具体数字**："十步、约八米"，并写明本段谁都不挪步、每个镜头里间距一样 | 作者看片说"两人距离忽远忽近" |
| **持械固定**：写进角色描述，不要在站位里再换说法 | 持剑手一度画成左手、反手 |
| **一个动作要符合物理**：空中劈下的人要写"稳稳落地、单膝收势"；裂痕方向和刀的方向一致；从空中掠过再降落要先有弧线 | 否则画成摔下来、裂痕歪着 |
| **近侧机位看不到远侧**：伤口写在朝向镜头的一侧；持械手要么写明在远侧、剑柄从身后露出，要么换一个看得见它的机位 | 伤在背面，镜头永远拍不到 |
| **没挂参考图的人不要写进站位**；没人的地方写明"除了两人，地面上没有任何人，也没有椅子和灯笼" | 作者的几段站位里写了前排三人，却没挂她们的参考图，模型在地面边上画了三个陌生人 |
| **接首帧的段，站位和上一段结尾一致**；第一镜写成"从这个画面出发，镜头怎么动" | 否则首帧锁死构图，第一镜和站位对不上 |
| **召唤物出现的位置写死**：在空中挥剑就从空中的剑弧里出来，写明"nothing rises from the floor" | 否则从地面长出来 |

## 4. 模板：全片状态表

复制后按你的故事填。"适用段"一列决定哪些段引用这一行。状态改变就新增一行，旧行保留，不要改旧行的文字。

| 项 | 状态说法（一字不改） | 适用段 | 状态改变的来由 |
|---|---|---|---|
| 方位 | {挑战者在哪半边、画面哪侧、面朝哪；对手同理；镜头留在连线的哪一侧} | 全片 | — |
| 座位 | {前排每个座位是谁；没到的人，座位空着} | {段范围} | {谁在哪一段到场} |
| 光线 | {光源方向、色、轮廓光} | 全片 | — |
| 尺度 | {人高关系；柱高 = N 个人高；场地宽 = 约 N 步} | 全片 | — |
| 场地 · 阶段 1（完好） | {材质、地标、柱子、旗帜、火} | {段范围} | — |
| 场地 · 阶段 2 | {阶段 1 的全部 + 新增的小范围损伤} | {段范围} | {哪一段哪个招式造成} |
| 场地 · 阶段 3 … | … | … | … |
| 角色 A · 完好 | {衣服、头发、配饰} | {段范围} | — |
| 角色 A · 受伤 1 | {阶段"完好"的描述 + 新增伤，写在朝向镜头的一侧} | {段范围} | {被哪一招打中} |
| 角色 A · 受伤 2 … | … | … | … |
| 角色 B · 完好 / 受伤 … | … | … | … |
| 召唤物 | {外形一字不差 + never changes shape or color} | {出场段} | — |
| 持械 | {哪只手、怎么握、拖剑时在哪} | 全片 | — |

## 5. 模板：衔接表（每段的结尾状态）

状态表管"一个阶段里是什么样"，衔接表管"这一段结束时停在哪"。写下一段之前，先看上一行。

| 段 | 结尾画面和机位 | 谁在哪（含间距数字） | 伤和场地处在哪个阶段 | 下一段开头怎么接 |
|---|---|---|---|---|
| {段号} | {清楚的姿势；机位在谁的哪一侧；景别} | {A 在画面左，B 在画面右，相距约 N 米} | {A 受伤 1；场地阶段 2} | {接续 / 硬切；第一镜从什么构图出发} |

## 6. 用法

1. 建节拍表之后、写第一段之前，先把"方位、座位、光线、尺度、持械"填满；这几行全片不变。
2. 打戏规划好以后，列出每个受损阶段，先出场地阶段图（`ref-images.md` 第 7 节），再把每张图的文字描述填进表。
3. 写每一段提示词时，**只复制表里的句子**；状态变了，先在表里加行、填来由，再写这一段。
4. 出片后发现某段不一致，先查是表里没写，还是写了没照抄，再改提示词；不要直接在这一段里补一句。
5. 改了某一行（例如改了座位顺序），先跑一遍 `scripts/check_script.py`，再按"适用段"列出所有引用它的段，逐段确认要不要重出。
