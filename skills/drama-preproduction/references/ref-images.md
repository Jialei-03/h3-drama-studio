# 参考图：人物定妆图、场景图、召唤物、受损阶段图

什么时候读：故事和角色卡定稿后，要给每个角色、场景、召唤物做视频用的参考图；或者视频里出现"脸不像""背景自己长出来了""场景状态前后不一致"，要回头查参考图。

## 1. 要做哪些图

| 类型 | 一张图里是什么 | 数量 | 为什么要单独做 |
|---|---|---|---|
| 人物定妆图 | 左边约 40% 是大的头肩特写，右边并排正、侧、背三个全身视图；16:9 | 每个有脸的角色 1 张 | 特写让中远景里的脸不糊、像；三视图给服装和背面 |
| 场景图 | 一个场景的全貌，实景质感，没有人 | 每个场景 1 张 | 不挂场景图，背景会被模型编成别的地方 |
| 召唤物图 | 单只、干净背景、全身、轮廓清楚 | 每个召唤物 1 张 | 三视图有被画成三只的风险，单张更稳 |
| 受损阶段场景图 | 同一个场景，在某个受损阶段的样子 | 每个阶段 1 张 | 场地破坏靠文字保不住，靠图保得住 |
| 特殊机位场景图 | 例：看台前排包厢 | 按需 | 看台镜头反复出现时，一张图锁死座位数量和位置 |

- 命名要带版本和用途，定稿后冻结，后续所有段只引用定稿名。例：`char_<角色>_v3.png`、`scene_<场景>_<阶段>.png`、`summon_<名字>.png`。
- **每个出现在画面里的有脸的人，都要有参考图。** 没挂参考图的人，不要写进这一段的站位（见 `state-table.md`）。
- 单段能挂几张取决于你的工作流；作者用的参考图生视频工作流最多 9 张，实际每段挂 2–7 张。

## 2. 出图路线：兼容 OpenAI 图像接口的服务

在 `config.yaml` 的 `image_api` 里填 `base_url_env`、`key_env`、`model`（填的是环境变量名，密钥本身不写进文件、不进日志、不放命令行参数）。

| 项 | 做法 |
|---|---|
| 带参考图编辑 | `POST /v1/images/edits`，multipart，参考图用字段 `image[]`，可传多张；不带参考图走 `/v1/images/generations` |
| 脚本 | `scripts/relay_img.py 输出.png 提示词.txt [参考图…] [--model] [--size]`：地址和密钥只从 `image_api.base_url_env` / `key_env` 指的环境变量读，模型默认取 `image_api.model`；`scripts/kf_batch.py 清单.yaml` 按清单批量并发出图（默认 4 张并发，失败重试一次；清单写法见 `examples/gemini-revenge/data/keyframes.example.yaml`）。两个脚本都有 `--dry-run`：只打印将发送的内容，不联网。状态：未在干净环境对真实服务端到端验证 |
| 速度（带参考图，1536×1024，单次实测） | 同一服务的三档：最好档约 66 秒/张；快档约 41 秒/张、质量接近；最省档约 35 秒/张但偏色、不太像参考图 |
| 用法 | 草稿用快档，定稿用最好档；4 张并发，28 张约 10 分钟（3840×2160，单次实测） |
| 备用 1：本地出图 | 作者试过本地的 H3-Image（bf16 配 nvfp4 文本编码器），约 100–150 秒/张，不支持 CFG；试完后选了接口，本地留作备用（单次实测） |
| 备用 2：命令行 agent 自带的出图工具 | 把推理强度调低，提示词开头写"直接调用出图工具生成，不要读文件、不要先做计划"，每张从 4–5.5 分钟降到约 130 秒（单次实测） |

- 常见故障：服务端按分组开关生图权限，没开时报"Image generation is not enabled for this group"，换调用方式没用，要去服务后台开。
- 作者对比过另一个本地开源出图模型，出来像游戏 CG、人物也不像参考，没有采用（单次实测）。

## 3. 画风写法：写成"真人实拍"，不写成"不要 CG"

- 提示词开头整段给画风：**真人实拍定妆照 / 好莱坞真人大片截帧**。要素：真人演员穿实物戏服、实景加数字扩景、电影摄影机质感、皮肤毛孔和布料纹理、特效合成进实拍、调色克制。
- 为什么：只写"漫威风"或"电影感"，出来仍是 CG 插画感；作者靠把画风写实到"演员 + 戏服 + 摄影机"这一级才压住。
- **排除项写成正面描述。** 想要暗的干地缝就写"地缝是暗的、干的灰色石头"，不写"不要红光"。为什么：这类出图和视频流程没有负面提示词，写"不要红光"反而会出红光。
- 想收一点绚丽感就直说"收敛、克制的调色"，要真人感就写"真人演员实拍"。

## 4. 人物定妆图

提示词骨架（把花括号换成你的角色卡内容）：

```text
以【参考图 1】的设计为底，重画成一张真人实拍定妆照：真人演员穿实物戏服，皮肤有毛孔，布料有真实纹理，柔和的影棚光，好莱坞真人大片的质感。
角色：{发型发色}、{眼色}、{服装关键件}、{配饰}、{道具}。{易漂移细节：眼色左右、领口有无、发型分缝方向}。
布局：16:9 横版，纯净的浅灰背景。左边约 40% 是同一个人的大幅头肩特写，头部端正平视，五官完整清楚；右边并排三个全身视图：正面、侧面、背面，三者大小一致、头顶和脚底对齐、鞋子完整入画。
画面里除了人物什么都没有。
```

- **有旧版三视图时，以它为参考图重画**成带大特写的新版（作者这样做）；只有文字设定时，先出一张全身图，再以它为底做这张。
- **把易漂移的细节写死**：左右眼不同色就写"右眼蓝、左眼金，瞳孔里没有星星、不发光"；特写里衣服会自己长出高领，就写"上衣没有领子"。为什么：作者的角色里，一句"瞳孔里的星亮了一下"就把异色瞳盖成两只蓝眼。
- **发型一旦定稿不再改**（例：顺直斜分的波波头）。参考图一换，已经出好的段就要重出。
- 在视频提示词里引用时写明分工：**"脸照这张图左边的大特写，服装照右边的全身视图"**。
- 一次出几个候选（换种子或换措辞）再挑；定稿要放大看原图，不看缩略图。
- 作者的成片里，文戏段用的是旧版定妆图（没有大特写），打戏段用的是带大特写的新版；两版在成片里脸部有没有差异，没有专门核对。建议一开始就做带特写的版本，全片统一。

## 5. 场景图

- 写成"一处真实的外景地"：材质（风化花岗岩、苔藓、磨损石板）、光线方向（低垂的夕阳在画面右侧）、天气和云海，不写成"游戏场景"。
- **写进空间设定**，同样的句子也要放进状态表的"尺度"行：直径或宽度（例：像体育场那么大，约两百步宽）、柱子几个人高、关键地标在哪、谁站哪半边。
- **每个镜头都要挂场景图。** 为什么：作者做关键帧时，没挂擂台图的镜头，背景自己变成白色大理石斗兽场。
- 一张场景图只可靠地管住和它同一角度的镜头；低机位和反打，模型会自己编（例：石碑被画成废墟或记分塔）。其他机位靠状态表里的地标文字补："石碑在擂台边缘""擂台在画面右上方、太阳旁边"。作者没有为每个机位各出一张场景图（未验证这样会不会更好）。
- 外景远景（山崖、云海）里，远处地标的位置要固定，每次都写在同一个位置。
- 看台、前排座位这类反复出现的位置，单做一张图：作者做了一张"前排包厢"图，写明"并排恰好三张石座"，所有看台镜头都挂它。

## 6. 召唤物图

- **单只、干净背景、全身、轮廓清楚**，不要三视图。
- 召唤物不必是主角的样子，动物或自然物（例：银龙、星辰灵猫）轮廓最清楚。
- 每一段只要召唤物出现就挂这张图，外形描述一字不差，并写 `never changes shape or color`。
- 它是不是"巨大的"由提示词和状态表的尺度行决定：人物是普通人的身高，只有召唤物巨大。
- 召唤物只在中景、全景、超远景出现，特写留给演员。见 `../../drama-scenes/references/summons.md`。

## 7. 受损阶段场景图

场景被打坏之后，每个阶段各做一张场景图，对应状态表的"适用段"。

- **做法**：以原场景图为参考图编辑，提示词只写变化，并写"其余一切保持原样"；带参考图约 40 秒一张（快档，单次实测）。
- **只让地面受损，柱子永远不坏。** 为什么：作者统计，地面的深渊和大坑写进文字能保住，断掉的柱子保不住（有三段里柱子又立了回来）。
- **只做小范围破坏**：石板碎裂、浅沟、浅坑、碎石、焦痕、熄灭的火、被撕走的旗帜。深渊、大裂谷、整块擂台崩塌，前后段很难保持一致；作者最终把带大坑和裂谷的结尾场景图重画成局部损坏。
- 阶段只增不减：后一阶段的图包含前一阶段的全部损伤。
- 伤和破坏的文字说法写进状态表，一段一段原样引用；图和文字说的是同一件事。

## 8. 验收清单（每张图）

- [ ] 放大到原尺寸看过，不是缩略图
- [ ] 脸清楚完整，五官没有糊或畸形；手指、四肢数量对
- [ ] 角色卡里的锁定项都在：发型、眼色、服装关键件、配饰
- [ ] 易漂移细节没漂（眼色左右、领口、分缝方向）
- [ ] 三视图头顶脚底对齐，鞋子完整
- [ ] 画面里没有文字、标签、水印、多余的人
- [ ] 画风是"真人实拍"，没有插画或游戏 CG 感
- [ ] 场景图里没有人；召唤物图背景干净
- [ ] 用户确认并定稿，文件名冻结

## 9. 常见翻车

| 现象 | 原因 | 办法 |
|---|---|---|
| 出图像插画或游戏 CG | 画风只写了"电影感" | 按第 3 节写到演员、戏服、摄影机这一级 |
| 写"不要红光"出了红光 | 排除项写成了否定句 | 改写成正面描述 |
| 背景变成别的地方 | 没挂场景图 | 每个镜头都挂 |
| 三视图被画成三个召唤物 | 对召唤物用了三视图 | 单张、干净背景 |
| 参考图换版后脸变了 | 已出好的段用的是旧版 | 换版前先决定哪些段要重出 |
| 特殊机位的场景被编出来 | 场景图只覆盖一个角度 | 用状态表里的地标文字补，必要时加一张机位图 |

关键帧（为每个镜头单独出一张起始画面）作者在打戏里已经放弃：它会带来不自然的运镜，见 `../../h3-video/references/tried-and-dropped.md`。
