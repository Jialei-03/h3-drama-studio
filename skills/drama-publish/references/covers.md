# 封面：无字底图、立体标题、横竖两版、嵌入视频

> 什么时候读：成片定稿后要做封面时；想改封面标题的位置或字体时；封面嵌进视频后某个软件里不显示时。

可信度：流程和提示词结构是《Gemini的复仇！》2026-11-22 至 24 做封面时定下的（**已验证**：横竖两版都经过多轮出图，标题位置也重新生成过）；出图耗时、图像模型的错字率是**单次实测 / 未统计**。

## 1. 流程

```
定妆图 + 场景图 + 召唤物图（参考图）
  → ① 出无字底图（海报，不带任何文字）
  → ② 在底图上让图像模型加立体标题字
  → ③ 横版 16:9 和竖版 3:4 各做一张
  → ④ 逐字核对标题 → 嵌入成片
```

图像模型用 config.yaml 的 `image_api`（兼容 OpenAI 图像接口的服务，需要支持传多张参考图的编辑接口）；带参考图每张约 1–2 分钟 [单次实测，视服务而定]。

## 2. 第一步：先出无字底图

**海报里不要同时画图和写字。** 为什么：图像模型写中文标题常常错笔画；底图和标题分开，标题错了只重出标题，底图可以反复复用，改标题、改位置都不用重画人物。作者最早的提示词里直接写了书法标题，随后就改成了"无字底图 + 后加标题"。

提示词结构（自己填空）：

```
一张院线电影海报，<与成片一致的画风，例：真人实拍的漫威超级英雄大片质感，不是动漫或游戏 CG>。
人物（脸照参考图左边的大特写，服装照右边的全身图）：
- 画面左侧是图片1里的 <角色 A>：外观、姿势、朝向、表情
- 画面右侧是图片2里的 <角色 B>：同上
- 两人之间隔着一段距离，正面对峙，<气氛：例：火花四溅里带一点喜剧感>
背景：图片3的 <场景>；<角色 B> 身后是 <召唤物虚影，参考图片4>……
版面：画面上不要出现任何文字、字母、数字、书法或标志。画面上方约四分之一是干净的天空，
留给之后加的大标题；画面最下方约五分之一较暗、干净，留给之后加的一行小字。人物放在画面中部。
```

要点：
- 参考图沿用定妆图（左大脸特写 + 右三视图）、场景图、召唤物图，保证封面上的人和片里一致。
- 画风、人物表情要符合片子的调性。喜剧片就让人物表情有戏（例：一个得意的坏笑，一个难以置信的不服气），别做成严肃的史诗海报。
- **明确留出标题和小字的空位**（上 1/4 天空、下 1/5 暗区）：给模型一个"空位"比只说"不要字"可靠。
- 先出几张挑一张，再进下一步。

## 3. 第二步：在底图上加立体标题字

把无字底图作为**图片 1**，提示词：

```
在图片1这张电影海报上加上大标题文字「<片名>」。除了加标题，人物、表情、背景、构图和色调全部保持原样不变，不要重画人物。
标题位置：……（见下表）
标题字体：……
文字要求：只写「<片名>」这几个字，每一笔都要准确，不能多笔少笔、不能有错别字；画面上不要出现任何其他文字、字母、数字或标志。
```

**字体要和片子的调性一致**：作者对比过毛笔书法和立体 logo 两种，喜剧向的《Gemini的复仇！》最终用立体"喵喵体"——粗圆胖乎乎，厚挤出侧面，正面粉紫到蓝紫渐变带果冻高光，外加一圈白描边、一圈深紫描边，整体微微倾斜、字高低错落；还能把角色特征做进字里（例：字母 G 头上长猫耳、感叹号的点是猫爪印、某个字旁边拖一条猫尾巴）。武侠、史诗向的片名更适合毛笔书法。

**标题大小和位置**（按作者的定稿，仅供参考）：

| | 横版 16:9（1536×864） | 竖版 3:4（1152×1536） |
|---|---|---|
| 标题宽度 | 占画面宽度 70%–85% | 约 90% |
| 字高 | 约占画面高度 1/5–1/4 | 约 1/8 |
| 位置 | 上方正中，两个人头顶之间的天空；可压在召唤物虚影前面 | 上方夕阳天空 |
| 禁区 | 绝不挡两个人的脸、头发、头饰 | 同左 |

本地排版（用字体渲染文字再合成）也可以：字绝对准、位置完全可控，但看起来像"贴上去的"，没有立体感；作者早期用过，最终发布的封面改用图像模型加字。

**每次出图都逐字核对标题**：错一笔就重出。必要时把"每一笔都要准确"再强调一遍，多出几张挑。

## 4. 横版和竖版各做一张

- 两张**分别出**，不要把横版裁成竖版：3:4 只占 16:9 画面宽度的约 42%（864 × 3/4 = 648，648 ÷ 1536），两个人物只能留下一个。竖版要重新构图：人物上下堆叠或拉开，召唤物放到各自人物的上方。
- 竖版同样先出无字底图，再加标题。
- 用途（作者 2026-11 的笔记，平台规则会变，以当时的发布页为准）：

| 平台 | 要的封面 |
|---|---|
| 小红书 | 竖版 3:4 |
| 抖音 | 竖版 3:4（推荐流、个人主页）+ 横版 16:9（横屏播放），两张都传 |
| B 站 | 横版 16:9；B 站会自动裁一张 4:3 用于部分场景，上传后检查标题有没有被裁掉 |

## 5. 想挪标题位置：重新生成

标题已经烤进封面里了，**不要用后期图像处理去挪**（标题带光晕和描边，抠出来容易留边；作者写过一个差分抠图的脚本，最终走的是重新生成；"抠出来留边"是推测，未验证）。做法是重新生成：

- 图片 1 = **无字底图**（人物、背景都以它为准）；
- 图片 2 = **旧封面**（只用来参考标题的字体、颜色、立体感，做成同一个 logo）；
- 提示词里重写位置：宽度占比、标题上方留多少天空（例：约 1/12 画面高度）、标题落在画面高度的哪个区间（例：8%–30%）、仍然不挡脸。

每次出 2 张候选挑一张。字体会有些微变化，所以要再核对一遍字。

## 6. 嵌入视频

把**横版封面**嵌成视频的"附图"（`attached_pic`），不重编码：

```
ffmpeg -i 成片.mp4 -i 封面_横版.jpg -map 0 -map 1 -c copy -disposition:v:1 attached_pic 成片_带封面.mp4
```

`scripts/embed_cover.sh 成片.mp4 封面.jpg 输出.mp4` 做同样的事，另外：封面不是 JPEG 会先转成 JPEG（只转封面）；成片里已有封面流会先去掉再嵌（可以反复嵌）；输出不能和成片同名。2026-11-24 复测：画面和音轨的码流 md5 与输入一致（没有重编码），用 PNG 封面、在已带封面的成片上重嵌都正常 [已验证]。检查：`ffprobe -show_entries stream=index,codec_name:stream_disposition=attached_pic 成片_带封面.mp4`，应该有一路 `mjpeg` 且 `attached_pic=1`。

- 嵌入在**字幕之后、配乐之前**（后期顺序见 `drama-postproduction`）：字幕一步会丢掉封面流，配乐和歌词两步会把它带过去。封面没做好就先跳过，最后用上面的命令补嵌（不重编码）。
- 成片的画面流必须仍是第 0 路视频流，封面是第 1 路。
- **嵌入的封面不是到处都生效**：支持附图的播放器和文件管理器会显示它；有些平台和聊天软件显示的是**视频第一帧**，嵌了也没用。平台上传时都要在发布页**单独传封面图**，不要指望嵌入。要让第一帧本身就好看，得在片头放一帧封面，但那会让之后所有时间平移 1 帧（见 `drama-postproduction` 的 rough-cut.md 第 6 节）；作者没有这样做。

## 7. 验收清单

- [ ] 标题逐字正确，没有多余的文字、水印
- [ ] 两个人的脸、头发、头饰没被标题遮住
- [ ] 人物、服装、场景和片里一致
- [ ] 横版 16:9 和竖版 3:4 各一张，文件名带片名
- [ ] 横版已嵌入成片，`ffprobe` 能看到 `attached_pic`
- [ ] 在小屏幕上缩小看：标题还能一眼读出来
