# AI 短剧：全流程总入口

总原则：**故事 > 提示词 > 工作流 > 模型**。出问题先查故事和提示词，最后才动工作流和模型（`references/lessons.md`）。

这是路由 skill：它告诉你现在在第几个环节、下一步交给谁、怎样算做完。具体怎么做，进对应的 skill。

## 开工前先问清三件事

1. **做到哪一步了？** 已经有什么：故事、参考图、剧本、已出的片段、粗剪。对照下表找到环节号。
2. **出片的机器通了吗？** 没有就从环节 0 开始；`config.example.yaml` 复制为 `config.yaml` 并填好（主机、ComfyUI 地址、模型文件名、出图接口的环境变量名）。
3. **要多长？** 显卡时间和片长大致成正比，先看 `references/pipeline.md` 的总账再定篇幅。

## 12 个环节

| # | 环节 | 交给 | 做完的标志 |
|---|---|---|---|
| 0 | 部署 | `local-ai-workstation` | 能出一段 5 秒测试片 |
| 1 | 故事与人设 | `drama-preproduction` | 节拍表和角色卡定稿 |
| 2 | 定妆与场景图 | `drama-preproduction` | 每个角色、场景、召唤物各有一张定稿参考图 |
| 3 | 剧本与状态表 | `drama-preproduction` | 每段有中英提示词，状态表覆盖全片 |
| 4 | 审稿 | `drama-preproduction` | 三遍审稿和机械检查都过 |
| 5 | 文戏出片 | `drama-scenes` + `h3-video` | 每段验片通过 |
| 6 | 武戏出片 | `drama-scenes` + `h3-video` | 逐段接续，接缝看不出来 |
| 7 | 验片与返工 | `drama-scenes` | 每段有留用的 take |
| 8 | 批量与通宵 | `h3-video` | 队列跑完，早上检查清单过一遍 |
| 9 | 粗剪与改稿 | `drama-postproduction` | 改稿清单清空 |
| 10 | 后期 | `drama-postproduction` | 音画等长、响度达标 |
| 11 | 发布 | `drama-publish` | 成片和横竖封面同名放在一起 |

每个环节的产出物、验收标准、用时和算力：`references/pipeline.md`。

**环节之间的规矩**：上一环节的产出物没有用户确认，不进下一环节。前期（1–4）不占显卡，改一句话几乎免费；出片（5–6）一段要十几分钟到半小时，所以改动尽量挡在前期。

## 这一段是文戏还是武戏

出片前先判断，两者的配置和写法不能混用（细节在 `drama-scenes` 和 `h3-video`）：

| | 文戏 | 武戏 |
|---|---|---|
| 内容 | 对话、走位、情绪 | 打斗、大招、召唤物 |
| LoRA | 不挂 | 武戏 LoRA 链 |
| 段长 | 最长 12 秒 | 5–10 秒 |
| 生成 | 可批量排队 | 一次一段，看完再写下一段 |
| 衔接 | 完整节点处硬切 | 接上一段末尾若干帧 |
| 用时 | 每秒成片约 1.5–2 分钟 | 每秒成片约 2.4–2.7 分钟 |

条件：RTX 5060 Ti 16 GB，1536×864，24 fps。

## 跨环节必守规则

| 规则 | 为什么 |
|---|---|
| **先故事，后提示词，最后才调工作流和模型。** | 作者看片的意见几乎都是剧情、台词、站位，没有一条是采样步数 |
| **照抄别人的工作流，要沿连线追到每个参数真正的值。** | 节点上显示的 1.5 倍只是摆设，真正生效的是 1.8 倍，抄错了一次 |
| **比较两个模型前，先查各自作者的真实用法。** | 拿为 A 写的配方去比 B，结论不公平 |
| **画质以看原片为准，不看缩略图和自编指标。** | 看片的人能看出缩略图里看不出的噪点 |
| **一次只改一个变量，固定种子。** | 否则分不清差异来自哪里 |
| **先给方案，批准后再动手。** | 剪辑和改稿会改变成片内容；没批准的不做进成片 |
| **写了的东西都会被画出来。** | 设定里一句"焦坑"每段都画出一个坑 |
| **排除项写成正面描述。** | "不要红光"出红光，"no slow motion"带进慢动作 |
| **武戏逐段生成，看完再写下一段。** | 整批排队，段与段对不上 |
| **改一段，后面接它的段都要重出，字幕、冲击帧、配乐时间跟着平移。** | 作者一次改稿牵动 15 段 |
| **用"已验证 / 单次实测 / 未验证"标注每个结论。** | 区分测出来的和猜出来的 |

## 时间与算力速查

条件：RTX 5060 Ti 16 GB、96 GB 内存、1536×864、24 fps。

| 项 | 数 |
|---|---|
| 文戏 | 每秒成片约 1.5–2 分钟（已验证）；10 秒一段约 15–21 分钟 |
| 武戏 | 每秒成片约 2.4–2.7 分钟（已验证）；10 秒一段约 24–27 分钟 |
| 带参考图出一张图 | 约 40–70 秒（单次实测） |
| 作者这部片 | 成片 3 分 44 秒，24 段留用；全项目生成 281 段，显卡累计约 84 小时 |
| 其他环节的人工耗时 | 未记录 |

预算时留出大量返工：作者的累计时间约是单遍理论值的 10–12 倍（推算，未验证）。算法见 `references/pipeline.md`。
