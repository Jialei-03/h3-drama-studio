# 全片状态表 + 段间衔接表

用在环节 3（剧本与状态表）。**这是整部片的场记**：每一段视频都是单独生成的，模型不记得上一段，所以方位、座位、光线、尺度、场地和人物状态、持械，都写成固定的一句话，每段的"站位"只由表里的句子拼成，不手写。
写法、规则和理由见 `skills/drama-preproduction/references/state-table.md`。花括号 `{}` 换成你的内容。

## 怎么用

1. 建节拍表之后、写第一段之前，先把"方位、座位、光线、尺度、持械"填满：这几行全片不变。
2. 打戏规划好以后，列出每个受损阶段，先出场地阶段图（`ref-images.md` 第 7 节），再把每张图的文字描述填进表。
3. 写每一段提示词时，**只复制表里的句子**。状态变了，先在表里加一行、填来由，再写这一段。**旧行保留，不要改旧行的文字。**
4. 出片后发现某段不一致，先查是表里没写，还是写了没照抄，再改提示词。
5. 改了某一行，先跑 `scripts/check_script.py`，再按"适用段"那一列找出所有引用它的段，逐段确认要不要重出。

## 一、全片状态表

"状态说法"一列是要原样复制进提示词的英文句子；`{}` 里写的是这一行该包含什么。

| 项 | 状态说法（一字不改） | 适用段 | 状态改变的来由 |
|---|---|---|---|
| 方位 | {挑战者站场地哪半边、画面哪侧、面朝哪；对手同理；镜头留在两人连线的哪一侧；场地上没有别的人} | 全片 | — |
| 座位 | {前排每个座位是谁；没到的人，座位空着} | {段范围} | {谁在哪一段到场} |
| 外景地标 | {远景里重要地标在画面里的固定位置。例：擂台始终在画面右上方、太阳旁边} | {段范围} | — |
| 光线 | {光源方向、色、轮廓光。例：金色夕阳，低垂的太阳在画面右侧} | 全片 | — |
| 尺度 | {人高关系；柱高 = N 个人高；场地宽 = 约 N 步}。能量和烟尘写成"比 X 还高、横跨半个场地"，不写"比柱子宽" | 全片 | — |
| 场地 · 阶段 1（完好） | {材质、地标、柱子、旗帜、火} | {段范围} | — |
| 场地 · 阶段 2 | {阶段 1 的全部 + 新增的小范围损伤：石板碎裂、浅沟、浅坑、焦痕} | {段范围} | {哪一段哪个招式造成} |
| 场地 · 阶段 3 … | {阶段只增不减；柱子这类地标永远不坏} | | |
| 角色 A · 完好 | {衣服、头发、配饰} | {段范围} | — |
| 角色 A · 受伤 1 | {"完好"的描述 + 新增伤，写在朝向镜头的一侧} | {段范围} | {被哪一招打中} |
| 角色 A · 受伤 2 … | {伤只累积、不消失} | | |
| 角色 B · 完好 / 受伤 … | | | |
| 召唤物 | {外形一字不差 + never changes shape or color；出手后回到召唤者身边做什么} | {出场段} | — |
| 持械 | {哪只手、怎么握、拖剑时剑在哪} | 全片 | — |
| 没参考图的人 | {例：Nobody else is on the arena floor; no spectators near the camera.} | 全片 | — |

## 二、规则速查（出问题时对照）

- 伤和破坏只累积、不消失；每次变化在画面里要有来由；落地、登场不破坏场地。
- 破坏只做小范围，场景状态靠参考图，不靠文字。
- 人物体型固定，只有召唤物巨大。
- 间距写具体数字（例："十步、约八米"），并写明本段谁都不挪步、每个镜头里间距一样。
- 近侧机位看不到远侧：伤口写在朝向镜头的一侧；持械手要么写明在远侧、剑柄从身后露出，要么换机位。
- 没挂参考图的人，不要写进站位。
- 接首帧或接续的段，站位和上一段**实际的**结尾一致。

## 三、衔接表（每段的结尾状态）

状态表管"一个阶段里是什么样"，衔接表管"这一段结束时停在哪"。**写下一段之前，先看上一行。填的是成片里实际看到的，不是剧本里写的。**

| 段 | 结尾画面和机位 | 谁在哪（含间距数字） | 伤和场地处在哪个阶段 | 结尾是不是好帧 | 下一段开头怎么接 |
|---|---|---|---|---|---|
| {段号} | {清楚的姿势；机位在谁的哪一侧；景别} | {A 在画面左，B 在画面右，相距约 N 米} | {A 受伤 1；场地阶段 2} | {清晰 / 闪白 / 糊} | {接续（22 帧）/ 硬切；第一镜从什么构图出发} |
| | | | | | |
| | | | | | |

- 结尾那一帧必须是好帧：清晰、构图和下一段开头一致；闪白、残影、糊帧不行。
- 动作没完成的交界用接续；停在完整节点的交界用硬切（见 `skills/drama-scenes/references/continuation.md`）。
- 文戏接武戏时站位最容易错：先把上一段实际的结尾站位和距离抄进这张表。
