# 改稿清单

用在环节 9（粗剪与改稿）。用户（做片的人）看完**编号全片**之后，意见一般是零散的口语：把它们整理成下面三张表，**每条意见只出现一次**。
流程和理由见 `skills/drama-postproduction/references/rough-cut.md`。整理完交给用户确认，再写剪辑方案（`cut-plan.md`）。

## 二、逐段表

只管某一段。**问题用"看到的现象"写，改法用"能执行的动作"写。**

| 编号 | 段 | 问题（看到的现象） | 改法 | 剪 / 补 / 换 |
|---|---|---|---|---|
| {02} | {g1b} | {例：g1 结尾镜头是拉远的，g1b 开头却变成推近再飞出去} | {例：接 g1 最后一帧，镜头不动，她直接冲天飞出} | {换} |
| | | | | |

三种改法，用最便宜且能解决问题的那个（剪 < 补 < 换）：

| 动作 | 用在哪 | 成本 |
|---|---|---|
| 剪帧 | 头尾穿帮、多余停顿、接缝处的残影 | 几秒，不用重新生成；画面和声音一起剪，剪完要重建音轨 |
| 补镜 | 一段里只有某一个镜头不行 | 一次生成 + 颜色匹配 + 看接缝 |
| 换段 | 整段动作、站位、台词不对 | 整段重出，加上受链式衔接牵连的后续段 |

## 三、需要重出的段（链式衔接决定范围）

武戏每段接着上一段的结尾生成：改了一段的结尾姿势或机位，后面接着它的段都要重出；文戏之间硬切、互不依赖。

| 改动的段 | 为什么要动 | 牵连的后续段（接它的） | 不用动的段 |
|---|---|---|---|
| {例：f1} | {去掉着火} | {f2 的首帧要换，f3 到 f8 跟着重出} | {g1、g2、f9、f10} |
| | | | |

**重出估时**：`Σ（段秒数 × 每秒成片用时）`。每秒成片约 1.5–2 分钟（文戏）、2.4–2.7 分钟（武戏）（RTX 5060 Ti 16 GB，1536×864，24 fps，见 `skills/h3-video/references/recipes.md`）；接续段每段多算约 0.9 秒。
