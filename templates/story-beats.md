# 故事节拍表

用在环节 1（故事与人设）。复制到你的项目目录后填写；花括号 `{}` 里是要你换掉的内容，"例："后面是作者片子的写法，填完删掉。
写法和理由见 `skills/drama-preproduction/references/story.md`。**先写这张表，再拆段、写提示词。**

## 三、打戏的升级阶梯

结构：势均力敌 → 各出绝招互拆 → 看似败局 → 反杀 → 终结大招 → 寂静。**至少 5 级，每一级都要改变局势。**

| 级 | 发生什么 | 谁占上风 | 这一级结束时和开始时有什么不同（伤、场地、召唤物） | 触发动作由哪一段埋下 | 预计段数 |
|---|---|---|---|---|---:|
| 1 | {例：对轰} | | | — | |
| 2 | {例：召唤物登场} | | | {例：上一段扬手 / 挥剑} | |
| 3 | {} | | | | |
| 4 | {} | | | | |
| 5 | {例：反杀（分身围攻）} | | | | |
| 6 | {例：终结大招} | | | | |
| 7 | {例：寂静} | | | | |

- 占上风的一方要接着出手，不要举着武器干等；换招、升空都要有被打断或借势的理由。
- 主角不打召唤物，伤害要落在对手本人身上。
- 召唤要有触发动作（扬手、挥剑），由上一段埋下。

## 四、台词规矩（照抄到你的项目里，按需改）

- [ ] 文戏每段至少两句，台词多、句子长，不留空镜
- [ ] 同一个梗不跨段复读，设定只交代一次
- [ ] 打斗中不说话；每人最多一个招牌大招，英文，动作中途喊出：{角色 A：招式名}、{角色 B：招式名}
- [ ] 点名说话人，倾听者闭嘴，一句台词不跨镜头
- [ ] 台词量按每秒 4–5 个汉字算
- [ ] 广播、画外音写成"从场地本身传来的声音"，画面里不出现播报员

## 五、验收（给用户看之前自查）

- [ ] 一句话讲得清这一集
- [ ] 每个节拍都有新信息
- [ ] 打戏至少 5 级升级，每级改变局势
- [ ] 全部台词列成一张表后，找不到意思相同的两句
- [ ] 每个角色有角色卡（`character-card.md`）
- [ ] 每个召唤物有触发动作，并在上一段埋下
- [ ] 最后有钩子
- [ ] **用户看过并确认**，再进入定妆图（`skills/drama-preproduction/references/ref-images.md`）
