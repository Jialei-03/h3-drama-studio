# 发布前检查清单

用在环节 11（发布）。成片和封面都定稿之后，交给用户之前逐项勾。**发布动作（登录、上传、选封面、勾选声明、点发布）由用户自己完成**，这份清单只管准备。
细节见 `skills/drama-publish/references/`（`covers.md`、`copywriting.md`、`export.md`）。

## 基本信息

| 项 | 填写 |
|---|---|
| 片名 | {用户选定} |
| 成片版本 / 导出日期 | {例：v16 / 2026-11-24} |
| 拟发布平台 | {抖音 / 小红书 / B 站} |

## 一、交付文件夹

```
<片名>_发布/
├── <片名>.mp4                    成片（已嵌入横版封面）
├── <片名>_封面_横版_16比9.jpg
├── <片名>_封面_竖版_3比4.jpg
└── <片名>_发布文案.md
```

- [ ] 成片和两张封面共用同一个片名前缀，放在同一个文件夹
- [ ] 只放交付物；中间版本（`_无冲击帧`、`_字幕`、`_配乐`……）留在工作目录，成片本身另存一份 master
- [ ] 成片太大不进 git 仓库，用外链
- [ ] 文件名里的全角标点上传正常（出问题就先去掉再试）

## 二、成片

- [ ] **流**：`ffprobe -v error -show_entries stream=index,codec_type,codec_name,width,height,r_frame_rate:stream_disposition=attached_pic -of default=nw=1 成片.mp4` → h264（1536×864、24/1）、aac、mjpeg（`attached_pic=1`）
- [ ] 画面流和音频流时长相差不超过 1 帧（0.042 s）
- [ ] 响度：整合约 −15 LUFS，真峰值 ≤ −1.5 dBTP（量法见 `skills/drama-postproduction/references/loudness.md`）
- [ ] **从头到尾带声音看完一遍**，不是抽看：字幕有没有错字、有没有压到画面边缘；每处冲击帧；配乐结尾和最后一句台词；片尾有没有多余的黑场或静音
- [ ] 用手机再看一遍
- [ ] 保持原生 1536×864、24 fps（放大不增加细节，转 30 fps 会引入抖动）
- [ ] 文件大小没超过平台上传限制（以发布页为准）
- [ ] 版本记录：成片文件名或旁边的记录里写明哪一版、哪天导出、量到的响度

## 三、封面

- [ ] 横版 16:9 和竖版 3:4 **各出一张**，竖版不是从横版裁的
- [ ] **逐字核对标题**，错一笔就重出
- [ ] 标题不挡人物的脸、头发、头饰
- [ ] 横版封面已嵌入成片（在字幕之后、配乐之前），`attached_pic` 在
- [ ] 每个平台**单独上传封面**，不依赖嵌入的封面（有些平台和聊天软件显示第一帧）

## 四、文案

- [ ] 片名有 6–8 个候选，用户选定
- [ ] 三个平台文案各一份，口吻是"我"，作者视角，有人味
- [ ] **中立、不拉踩**：玩笑落在剧情里，不落在对真实产品的评价上
- [ ] **没有未核实的事实**：版本名、榜单和排名、发布时间、人名公司名、"第一个"类断言。不确定的用"印象里""我觉得"，或删掉
- [ ] "本地制作"的说法和实际流程一致：视频在本地生成，参考图或封面走了在线图像接口就不要写"全程本地"
- [ ] 标签数量符合平台限制
- [ ] 文案文件末尾附"待核实清单"（凭记忆写的事实逐条列出），交给用户核实

## 五、声明与版权（用户在发布页操作）

- [ ] 提醒用户**勾选各平台的 AI 生成声明**（成片里不烧声明，由发布页开关标识）
- [ ] **背景音乐的版权**：授权范围覆盖这个平台和商用 / 非商用；保留授权证明；平台的版权识别可能仍会命中，拿不准就换平台自带曲库或免版权的歌
- [ ] 歌词字幕同理，歌词也有版权
- [ ] 第三方的配方、模型、LoRA 在简介里署名（建议写法见 `skills/h3-video/references/credits.md`）；没有附带别人的文件

## 六、交给用户时一并说清

- [ ] 哪张封面传到哪个平台
- [ ] 每个平台要勾选的声明
- [ ] 文案里的"待核实清单"
- [ ] 发布后下载或播放一次平台上的版本，看转码后的画质是否可以接受
