# 剪辑方案

用在环节 9（粗剪与改稿）。**先给方案，批准后再动手：没批准的剪辑，一帧都不要做进成片。** 一次给全，不要一条一条问。
理由：剪辑一旦做进带字幕和配乐的成片，撤销要把后面的步骤全部重做一遍。流程和规则见 `skills/drama-postproduction/references/rough-cut.md`。

| 帧率 | {24} fps：剪的是帧数，时间 = 帧数 ÷ 24 |

## 方案表

每条写"位置 + 动作 + 理由"，理由写不出来的剪辑不要提。"对后面的影响"是这一剪之后所有时间平移多少。

| 编号 | 位置（时间点 / 帧号） | 动作 | 理由 | 对后面的影响 | 是否批准 |
|---|---|---|---|---|---|
| {06} | {0:41.7（或写帧号）} | {剪 6 帧，画面和声音一起剪} | {例：去掉一处多余停顿} | {其后所有时间 −0.25 s} | {待批 / 批准 / 驳回 / 改为……} |
| | | | | | |
| | | | | | |

动作只有三种（用最便宜且能解决问题的）：

- **剪帧**：剪点放在硬切、白光、爆炸这类本来就有跳变的地方；连续运镜中间剪会跳 [未验证]；画面和声音一起剪，帧数一致。
- **补镜**：单独生成一个新镜头替换或插入，同一套配置，从前一个镜头的结尾写起；替换后检查前后两个接缝。
- **换段**：整段重出，加上受链式牵连的后续段；先写出牵连范围再估时间。

## 时间平移表

每剪一处就更新一次。所有后期阶段的时间常量都按"剪前时间线"写，经过 `shift(t)` 再用。

| 剪点（剪前时间线，秒） | 剪掉的帧数 | Δ（秒） | 累计 Δ（秒） |
|---:|---:|---:|---:|
| {41.7} | {6} | {−0.25} | {−0.25} |
| | | | |

换成不同长度的片：Δ = 新长度 − 旧长度，同样进这张表。

## 连锁影响（逐项勾）

| 阶段 | 受什么影响 | 怎么平移 | 已处理 |
|---|---|---|---|
| 拼接 / 音轨 | 画面和音轨都变 | 重新拼接、重建音轨（`scripts/splice.py`、`scripts/fix_audio.py`） | [ ] |
| 冲击帧 | 按帧号写的位置 | 帧号 −N，每处肉眼复核 | [ ] |
| 字幕 | 每张卡的起止秒 | 剪点之后的卡片 −N/24 s；在新音轨上重测 | [ ] |
| 配乐 | 对齐常量（歌曲时间 → 片中时间的偏移） | 剪点在配乐开始之前：整条音乐提前 N/24 s；剪点落在配乐范围内：音乐不剪，重新倒推对齐 | [ ] |
| 歌词 | 同一个偏移 | 同步改 | [ ] |
| 响度稳定、推高、喊招增益 | 各自写死的时间窗 | 同一个平移函数 | [ ] |
| 封面 | 不受影响 | — | — |

做法：**从最早受影响的阶段重跑，不在成片上打补丁**。每个阶段的输出都留一份（`_无冲击帧`、`_冲击帧`、`_字幕`、`_配乐`、`_歌词`），出新版用新文件名。

## 做完之后的核对

- [ ] 平移是算出来的、会累计误差：**抽查至少三处**（开头、中间、结尾）
- [ ] 字幕对嘴型；冲击帧落在声响上；配乐最后一个重拍落在最后一个大招上
- [ ] 画面时长和音轨时长相差不超过 1 帧；最后一句台词的最后一个字完整
- [ ] 做新一版编号全片，回到 `revision-list.md` 逐条打钩
